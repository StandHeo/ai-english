## 摘要

华语家庭给 4–6 岁孩子练英语口语时，常见选择落在三类：**体系课 App**（叽里呱啦、洪恩、斑马）、**绘本/拼读**（伴鱼绘本、Duolingo ABC）、**AI 虚拟外教**（Buddy.ai 等）。它们普遍更强的是「课程完整、内容海量、发音打分」；更弱的是「今晚 10 分钟、孩子愿意再开口、内容像自家生活」。

本产品不与它们拼 CEFR、自然拼读或牛津版权库，而是占一个更窄的楔子：

**故事冒险推进口语**（说短词才能往下走）+ **永不卡死的支架**（期望词匹配 + 点图兜底）+ **今晚可玩的家庭内容**（官方主题包 + 日记生成关）。

若验证成功，护城河不在「课最多」，而在 **共玩仪式** 与 **把今天的生活变成可开口关卡**。

## 1. 本品定位（对照基准）

| 项 | 说明 |
|----|------|
| 用户 | 4–6 岁儿童（全英游玩）+ 家长（中文家长页、日记工作室） |
| 场景 | 晚上约 10 分钟窗口；家长共玩，目标是「顺利过一小关、觉得好玩、愿意明天再开」 |
| 核心玩法 | 主题地图 → 听 / 找 / 说目标短词 → 贴纸与星星；故事靠开口推进 |
| 内容 | 官方包：水果森林、自行车世界、机器人实验室、英雄世界、小狗救援队、钓鱼日、游泳日；另有家庭日记当晚生成关 |
| 技术姿态 | Android 优先（Web + Capacitor）；关卡 JSON 脚本驱动；ASR 期望匹配而非开放闲聊；进度与日记本地优先 |
| 明确不做 | 商业化、完整课程体系、儿童自由聊天、社交、生产级 CMS |

一句话：**不是练习册，也不是聊天机器人，而是「说一句、故事往前走」的短课时冒险。**

```text
家长目标谱

 刷完体系课 / 对标小学     愿意开口、好玩、像自己的生活
        │                              │
        ▼                              ▼
  斑马 / 叽里呱啦 / 洪恩            ★ 本品楔子
  伴鱼绘本 / 开心鼠                 家庭日记 + 主题冒险
        │
        ▼
  Buddy.ai / Speech Blubs          开口强，但内容是通用课
```

## 2. 赛道怎么切

儿童英语不是一块铁板。按「孩子晚上真正在做什么」切，比按品类名切更清楚：

| 层 | 孩子在做什么 | 家长买的是什么 | 典型产品 |
|----|--------------|----------------|----------|
| A. 熏听 / 看动画 | 被动听、唱、刷 | 语感、省心 | Super Simple Songs、小猪佩奇、宝宝巴士 |
| B. 点选游戏课 | 点图、跟动画课点选项 | 体系、进度条、教研背书 | 斑马 AI 学、叽里呱啦、洪恩英语、开心鼠 |
| C. 阅读 / 拼读 | 跟读绘本、字母解码 | 阅读力、小学衔接 | 伴鱼绘本、Duolingo ABC、牛津分级 |
| D. 开口陪练 | 对着角色/视频说话 | 「敢说、纠音」 | Buddy.ai、Speech Blubs、洪恩口语城、Lingumi |
| E. 真人外教 | 1 对 1 视频课 | 社交与纯正口音 | 伴鱼少儿等（价高、难塞进每晚 10 分钟） |
| F. 生成式故事 | 用照片/名字生成绘本 | 个性化、新鲜感 | Once Upon A、LoreZest、通用大模型 |
| G. 家庭生活进内容 | 用今天发生的事练英语 | 亲子连接 + 开口 | **本品家庭日记 / 家庭实拍关**（竞品几乎空白） |

本品主战场是 **D + 轻度 B 的冒险外壳 + G**。  
不是 A（纯看），不是 C（拼读主线），不是 E（排课），也刻意不做开放式 F（儿童自由聊）。

## 4. 分组深挖

### 4.1 国内体系课：教研厚、开口弱于「课感」

| 产品 | 公司 / 生态 | 年龄与形态 | 口语怎么练 | 相对本品 |
|------|-------------|------------|------------|----------|
| **叽里呱啦** | 独立品牌，宣称 0–8 岁、6000 万家庭量级 | AI 体系课 + 生活实景/动画；听说先行、拼读进阶 | 课程内开口练习、场景对话；强动画主线 | 更像「每天上一节课」；生活场景是教研拍的，不是今晚家里发生的事 |
| **斑马 AI 学** | 猿辅导；2025-01 MAU 约 386 万（行业表） | 英语只是七大学科之一；AI 互动课 + 辅导老师 | 口语评测、自适应路径；短课时适合低龄 | 家长买的是能力图谱与督学，不是 10 分钟共玩冒险 |
| **洪恩英语** | 洪恩 / iHuman；识字 MAU 更高 | 字母→单词→整句→对话；BBC 动画 + 牛津绘本 | **口语城** NPC、外教视频 + AI 纠音 | 最像本品的「场景闯关开口」；但内容是超市/餐厅通用城，纠音更严，课程更长 |
| **开心鼠英语** | 腾讯 × ABCmouse 路线 | 3–8 岁一站式听说读写；护眼/时长 | 口语 + AI 评测，再加拼读阅读 | 国际课标与激励宠物，偏「完整学校」 |
| **学而思启蒙**（原小猴启蒙） | 好未来 | 思维/口语等，内容相对少 | 表达/口语模块 | 教研背书强，英语单科存在感弱于叽里呱啦 |
| **瓜瓜龙启蒙** | 字节跳动 | 中英文主题动画 | 偏看与轻互动 | 流量与动画，不是口语关卡机 |

**家长为什么选他们：** 怕启蒙走偏、要对标小学/新课标、要「有人管进度」。  
**本品不必正面硬刚：** 课量、版权动画、督学、拼读路径都不是短期能追上的资产。  
**可借鉴：** 洪恩口语城的「说了 NPC 才反应」；叽里呱啦的生活实景（我们用家庭实拍/日记做到「更像我家」）；斑马的短课时。

### 4.2 绘本与拼读：输入强、冒险弱

| 产品 | 形态 | 与本品关系 |
|------|------|------------|
| **伴鱼绘本** | 4000+ 分级绘本，讲-听-录-练，AI 跟读打分 | 开口是跟读，不是推进剧情；家庭价值是「选书省心」 |
| **Duolingo ABC** | 免费无广告，3–8 岁字母/拼读/早期阅读 | 母语儿童识字工具，不是 ESL 开口 |
| **Lingokids** | 2–8 岁 Playlearning，歌曲游戏词汇，订阅 | 好玩、词汇广，说话不是过关条件 |
| **Khan Academy Kids / ABCmouse** | 综合早教 | 英语只是一科，无故事口语状态机 |

本品若去做「分级阅读主线」，会掉进伴鱼/牛津的内容战争。更合理的关系是：**冒险里偶尔出现找一找、跟读拍**（已有 `find` / 多样 `npc_say`），阅读仍让位给绘本 App。

### 4.3 国际开口向：最像本品的「玩法近亲」

| 产品 | 年龄 | 开口机制 | 差异 |
|------|------|----------|------|
| **Buddy.ai** | 约 3–8 | 对着虚拟导师说话；PPP 课（热身-呈现-练习-产出）；1500+ 词；章节故事 | **最近的国际对标。** 强在 1:1 语音与课程结构；弱在内容是 Animals/Colors 通用课，没有「今天去钓鱼」；偏孩子自己练，不是家长共玩 |
| **Lingumi** | 约 2–4 | 约 10 分钟；游戏里必须说出目标词才能继续 | 机制极像本品「说了才往下」；更低龄、更短、更课程化，无家庭生成关 |
| **Speech Blubs** | 言语发展 / 构音 | 看同龄视频模仿口型 | 治疗辅助，不是英语冒险 |
| **EnglishCentral Kids** | 更大学龄 | AI 纠音 + 真人课 | 价与年龄都偏上 |
| **Voiczy 等新入口语 App** | 低龄多语 | 强调「真的开口」对比 Duolingo ABC | 验证了「点选课 ≠ 开口课」的市场叙事，内容仍是通用路径 |

**关键结论：** 开口机制（说了才继续、短课时、角色陪伴）国际已有验证；**把开口嵌进「我家今天」** 仍少见。Buddy.ai 是功能近邻，不是场景近邻。

### 4.4 生成式个性化：像「我家」但多半不能玩

| 产品 | 做什么 | 缺什么 |
|------|--------|--------|
| **Once Upon A** | 照片卡通化，生成带孩子形象的插画故事；按词/难度定制 | 偏听读；公开信息以中文等语言阅读为主，不是按住说话闯关 |
| **LoreZest 等** | 姓名/外貌/兴趣生成绘本 + 听读 + 词测 | 生成故事，不是关卡状态机；无点图兜底口语环 |
| **ChatGPT / 豆包等** | 家长口述「编个英语小故事」 | 无幼儿 UI、无匹配与永不卡死、安全与时长不可控；儿童若直接聊则踩本品明确禁止的自由聊天 |

本品家庭日记的独特组合是：

```text
今晚发生的事（语音/文字，端侧 Whisper）
        → DeepSeek 生成符合 LevelScript 的短词关
        → 相册/通义配图（可占位，不阻塞开玩）
        → 孩子用同一套 听/找/说 玩，日历囤关
```

竞品多停在「生成一本故事书」或「生成一段对话」；很少把生成结果送进 **已验证的口语关卡播放器**。

### 4.5 替代品（抢同一段晚上时间）

不装英语 App 的家庭，时间往往给了：

- YouTube Kids / 儿歌动画（零摩擦、零开口）
- 家长用手机让孩子「跟读一句」或对大模型说话（不可控、易变成闲聊）
- 纸质闪卡、洪恩贴纸书（共玩强，无语音闭环）

本品要赢的是这段 **10 分钟**，不是「英语品类份额」。成功标准见 `docs/parent-child-ux-notes.md`：来得及鼓掌、看见贴纸、愿意明天再打开。

## 6. 同一晚 10 分钟：体验差在哪

以「洗完澡、还愿意再玩一关」为镜头：

| | 体系课 App | Buddy.ai 类 | 绘本 App | 本品设计意图 |
|--|------------|-------------|----------|--------------|
| 开始摩擦 | 选课、登录、广告/续费墙 | 选课级、热身闲聊 | 选书定级 | 首页大图点进主题；家庭入口在门禁后 |
| 孩子做什么 | 看动画 + 点选 + 偶发跟读 | 对角色说话、游戏穿插 | 听读、跟读打分 | 听示范 → 找图 → 按住说短词 |
| 说错了 | 低分、重读、家长焦虑 | 再试，课程节奏仍在 | 打分打击 | 支架重试 → 点图兜底，故事继续 |
| 结束 | 课时完成、星星、明日任务 | 课结束 | 一本书读完 | 贴纸仪式（规格上强调被看见） |
| 和今天的关系 | 无 | 无 | 无 | 钓鱼/骑车实拍；日记关就是今天 |

体系课输在 **课感与失败惩罚**；Buddy 输在 **不是我家的故事**；绘本输在 **开口不是冒险**。本品的风险则是：工业完成度不够时，孩子觉得「没有洪恩好看」，或听窗/匹配过严，学会「乱说再点图」（家长笔记里已标为 P1）。

## 7. 差异化：该守什么、不该吹什么

### 7.1 真正可守的差异（建议对外只讲这三句）

1. **说了故事才走**：口语是玩法，不是课后作业。  
2. **卡不住**：认错、害羞、ASR 不准，都可以点图过，保护「还想玩」。  
3. **今晚的生活能变成一关**：官方主题包解决「有得玩」；日记工作室解决「像我们家」。

### 7.2 不要当成卖点去硬碰的

- 词汇量、级别数、外教人数、牛津/BBC 版权  
- 音素级纠音、剑桥备考  
- 多学科、辅导老师、能力图谱  
- 儿童与大模型自由聊（规格明确禁止；也是安全与品牌风险）

### 7.3 潜在壁垒（做对了才存在）

```text
手写主题包（水果/车/机器人/英雄/狗/钓鱼/游泳）
        + 家庭实拍进关（视频短播后定格）
        + 同一套 LevelScript 播放器
        + 日记 LLM → 校验短词关 → 日历回看
        + 共玩节奏（听窗、仪式、不自动连玩）
```

内容工厂可以抄「水果关」；难抄的是 **播放器契约 + 家庭生成管线 + 4 岁共玩手感**。Buddy 难抄家庭日记；Once Upon A 难抄口语状态机与兜底。

## 8. 威胁与替代

| 威胁 | 为何危险 | 应对姿态 |
|------|----------|----------|
| 洪恩把口语城做得更好玩、更短 | 玩法近、品牌与动画碾压 | 不拼城市场景；把「我家」做到他们做不到的颗粒度 |
| 叽里呱啦/斑马加「今日生活」AI 课 | 有教研与分发，可能快速做一个浅版 | 比深度：当晚可玩、同一套听找说、点图兜底、日历囤关，而不是生成一段动画课 |
| Buddy.ai 或国内 AI 分身进华语家庭 | 开口体验成熟 | 强调共玩与家庭内容，避免做成「孩子单独跟机器人聊」 |
| 大模型直接进儿童端 | 家长觉得「更智能」 | 坚持脚本 + 审核/校验；LLM 只在家长侧生成关卡，不对儿童开放闲聊 |
| 儿歌/动画抢走时长 | 零失败、更好看 | 通关仪式与贴纸必须「被看见」；失败代价必须低于关掉 App |
| 家长工作室太工程（Key、阈值） | 日记差异化根本用不起来 | 这是当前最大的「有能力、无体验」缺口（见家长笔记 P1） |

## 9. 对产品的启示

按「竞品会如何打我们 / 我们如何不被收编」排序，而不是功能愿望清单。

### 9.1 守住楔子（优先级最高）

- 继续把 **开口过关 + 永不卡死** 当成体验底线：听窗、乱说点图的节奏要调到「愿意说」，而不是「会刷兜底」。  
- 通关仪式与贴纸墙要接到「今晚这一关」，否则在洪恩/斑马的奖励工业面前会显得空。  
- 家庭日记从「能生成」变成「妈妈今晚愿意用」：藏起 API Key 心智，默认当晚能玩。

### 9.2 内容策略：少而极像生活，而不是多而像机构

- 官方包走 **孩子真会碰到的主题**（已有骑车、钓鱼、游泳、英雄、救援）优于再开「机场/超市」去撞洪恩口语城。  
- 家庭实拍（视频短播后定格）是低成本差异，值得在更多包复用，而不是先上 CMS。  
- 生成关质量标准保持「能开口的短词」，不要用体系课的完整度衡量日记关。

### 9.3 竞争叙事（对内）

| 有人问 | 建议回答 |
|--------|----------|
| 和叽里呱啦/洪恩比课全吗？ | 不比。他们是学期产品；我们是今晚共玩。 |
| 和 Buddy 比谁更 AI？ | 儿童端更克制。AI 用在家长把今天变成关卡，不用在孩子闲聊。 |
| 和伴鱼比阅读吗？ | 不比。我们练的是开口推进故事。 |
| 以后要不要拼读/分级？ | 验证「还想再玩」之前不要做；做了就变成第十个体系课。 |

### 9.4 验证指标（比 MAU 更早该看的）

面向内测家庭，建议只盯竞品抢不走的行为：

1. 当晚是否玩完 **一关**（不是是否学完一课）  
2. 口语拍是否 **真的说话**（相对直接点图）  
3. 通关后是否 **还想再开一关 / 明天还打开**  
4. 日记关是否 **当周至少用过一次**（差异化是否落地）
