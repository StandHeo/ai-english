# 微信传 APK 安装说明

用微信把安卓安装包（`.apk`）发给朋友时，文件常被拦截或改后缀。按下面步骤一般就能装上。

在线版（临时 IP）：http://118.24.164.40/wechat-apk-install.html  
短地址：http://118.24.164.40/wechat-apk

## 常见现象

微信会把 `xxx.apk` 改成 `xxx.apk.1`、`xxx.apk.bak`，或直接不让点开安装。群聊/朋友圈更容易被拦，私聊文件也可能失败。

## 收到文件后怎么装（安卓）

1. 在微信里打开该文件，选「用其他应用打开」或「保存到手机」，保存到「下载」或「文件」目录。
2. 打开手机自带的**文件管理**，找到这个文件。
3. 看后缀：如果不是 `.apk`，长按 → 改名，去掉多余部分，只保留 `.apk`。  
   例如：`app-debug.apk.1` → `app-debug.apk`。
4. 点这个 `.apk` 开始安装。
5. 若提示「禁止安装未知应用」：到系统设置里，给**文件管理**（或你用来打开 APK 的应用）打开「允许安装未知应用」，再回来点一次安装。

## 包名换过之后要注意

- 新包名是 `com.tudoudou.aienglish`（显示名「土豆豆AI英语」）。
- 如果手机上还装着旧的「Fruit Forest」/ `com.aienglish.fruitforest`，建议**先卸载旧版**再装新包，避免装不上或桌面图标、数据混乱。

## 更稳的传文件方式（推荐）

想少被微信改名或拦截，可以改用：

- 网盘发链接（夸克、百度网盘、坚果云等）
- QQ 传文件
- 蓝牙 / 数据线

开发者本机调试也可用 `adb install xxx.apk`，那是给你自己用的，不用发给朋友。

## 安装仍失败时

- 确认文件大小完整（下载没中断）。
- 确认已改回 `.apk` 后缀。
- 确认已允许「未知来源 / 未知应用」安装。
- 换一台文件管理器再试，或换网盘下载后再装。
