土豆豆AI英语 · API Key 获取说明

家庭日记 / 每日关卡需要家长自备 AI 密钥（BYOK）。密钥只保存在你的手机里，不会由土豆豆代充算力。目前支持 Agnes（推荐免费入门）和 DeepSeek（脚本更稳）。

本页目录 一、Agnes API Key（推荐免费档） 二、DeepSeek API Key 三、填进土豆豆AI英语 四、安全提醒

一、Agnes API Key（推荐免费档）

注册并拿到 Key（约 2 分钟）

  1. 打开 Agnes 开发者平台：
    https://platform.agnes-ai.com
  2. 用邮箱注册，或使用 Google / GitHub 登录。
  3. 进入 设置 → API 密钥（英文界面多为 Settings → API Keys）。
  4. 点击 创建新密钥（Create new secret key）。
  5. 立刻复制并保存密钥（一般以 sk- 开头）。页面通常只显示一次，关掉就看不到了。
免费档通常不需要绑卡或充值也能用。主要限制是每分钟请求次数；太快失败时稍等再试即可。配图也可选 Agnes 图，与日记共用同一把 Key。
Base URL：https://apihub.agnes-ai.com/v1
推荐文本模型：agnes-2.5-flash（以向导当前推荐为准）

二、DeepSeek API Key

注册并拿到 Key

  1. 打开 DeepSeek 开放平台（不是 chat.deepseek.com 聊天站）：
    https://platform.deepseek.com
  2. 用手机号 / 邮箱注册并登录（和聊天 App 账号通常不通用，需要单独注册开放平台）。
  3. 左侧进入 API Keys，或直接打开：
    https://platform.deepseek.com/api_keys
  4. 点击 Create new API key / 创建新密钥，起个名字（如「土豆豆」）。
  5. 立刻复制密钥（一般以 sk- 开头）。同样只显示一次。
DeepSeek API 一般是预付费：需要在开放平台 充值 / Billing 里有余额后，密钥才能正常调用。新用户偶有赠额，以平台当时规则为准。单价通常很低，生成一篇日记脚本大多远小于 ¥0.1。
接口地址（App 内置，一般不用手填）：https://api.deepseek.com/chat/completions
推荐模型：deepseek-chat

三、填进土豆豆AI英语

  1. 打开 App → 进入家长设置 / 模型配置向导（需家长门禁）。
  2. 文本（关卡脚本）提供商选 Agnes 或 DeepSeek。
  3. 把对应的 API Key 粘贴进去：只粘贴密钥本身，不要加 Bearer，前后不要空格。
  4. 两家 Key 可以都填好，切换提供商时各自生效。
  5. 点保存 / 测试连通。成功后再去生成一篇家庭日记验证。

四、安全提醒

  • Key 相当于密码：不要发到微信群、朋友圈或发给客服以外的人。
  • 土豆豆 Plus 只解锁日记工作室和配置向导，不包含 Agnes / DeepSeek 等第三方模型费用。
  • Agnes 文档：https://wiki.agnes-ai.com/zh-Hans/docs/quickstart
  • DeepSeek 文档：https://api-docs.deepseek.com
若打不开 platform.agnes-ai.com 或 platform.deepseek.com，多半是当前网络限制，可换 Wi‑Fi / 蜂窝网络后再试。
