## 0. 一页纸

| 项 | 决策 |
|----|------|
| 市场 | **中国大陆先上**；海外以后再说；**不同时双开海内外商店** |
| 形态 | iOS 与 Android **都走官方商店 App**；技术栈继续 **Capacitor + Web** |
| 买家 | 卖给 **4–6 岁孩子的家长**；儿童路径上 **不出现价格** |
| 产品 | **每晚约 10 分钟共玩**，不是课程体系 |
| 权益 | **家长订阅**。免费：完整水果森林 + 现有每日时长上限。会员：其余官方包 + 有上限的家庭日记生成 |
| 支付 | **两条支付轨、一份权益**：iOS 走 Apple IAP；Android 走微信 / 支付宝（或国内应用商店代收）。会员资格落在 **服务端**；手机号登录；可跨设备、跨系统恢复 |
| 价格 | **¥18 / 月**，**¥148 / 年**（约 **¥12.3 / 月**）。**不做买断终身** |
| 不做 | 不把打赏当主收入；儿童路径不设付费墙 / 广告；**App Store 提交后禁止用微信解锁码卖付费内容** |

**硬规则：** 一旦提交 App Store，解锁付费内容 **必须** 走 Apple IAP。微信 + 解锁码只允许作为 **上架前内测**，审核前必须关掉。

**与竞品文档的边界变化：** [`docs/competitive-analysis.md`](competitive-analysis.md) 曾写「明确不做商业化」。本方案改变该产品方向边界：可以收费，但仍不做完整课程体系、儿童自由聊天、社交或生产级 CMS。

```text
家长付一次会员
        │
        ▼
  服务端一份权益 ──► iPhone / Android 平板都能用
        │
   ┌────┴────┐
   │         │
 Apple IAP   微信 / 支付宝（国内 Android 商店）
```

## 1. 现状（对照本仓库）

当前版本 **v0.1.0**。还没有账号，也没有云同步。

| 项 | 现在怎样 |
|----|----------|
| 账号 | 无。进度与日记都在本机 |
| 家长门禁 | 算术题只挡设置页，不是付费门 |
| 家庭日记 Key | DeepSeek / 通义等云 Key **存在本机** |
| Android | Capacitor 8；包名 `com.aienglish.fruitforest`；展示名 **Fruit Forest**。仓库 **没有** `android/`；也 **没有** GitHub Releases。APK 靠本机 Android Studio 打 |
| iOS | 文档写的是 **侧载、不上架**；没有 StoreKit |
| 官方关卡 | 手写 JSON + 静态资源，边际成本接近 **零** |
| 日记关卡 | 每次生成要烧脚本与（可选）配图，**不是** 零边际成本 |

一句话：现在能玩、能侧载，但还不能在商店卖、也不能跨设备认同一份会员。

## 2. 三条可卖的话（只讲这些）

对外只讲这三句（与竞品分析 7.1 对齐）：

1. **说了故事才走**：孩子开口，剧情才往前。  
2. **永不卡死**：认错、害羞、ASR 不准，都可以点图过。  
3. **今晚的生活能变成一关**：官方包保证有得玩；日记工作室把今天变成可开口关卡。

**不要拿来卖的：**

- 词汇量、级别数  
- CEFR / 课标进度  
- BBC / 牛津版权库  
- 音素级打分  
- 儿童与大模型开放闲聊

## 3. 国内双端商店

| 端 | 商店 | 收款 | 说明 |
|----|------|------|------|
| iOS | 中国区 App Store | **必须** Apple IAP | 上架后不能再用微信解锁码卖付费内容 |
| Android | 华为 / 小米 / 应用宝等 | 微信 / 支付宝，或商店代收 | v1 至少先选一家 |

**权益在服务端。** iPhone 订的会员，同一家长账号在 Android 平板上也生效。客户端只问「这份家庭现在是不是会员」，不问「这笔钱是哪条轨收的」。

**上架前可选：** 侧载包 + 人工解锁码，方便亲友内测。  
**提交 App Store 当天必须关掉** 解锁码通道。之后只走 IAP。

**打赏不是方案。** 不把赞赏码、红包、自愿打赏当成主收入，也不用它绕过商店规则。

## 4. 为什么是订阅，不是买断

日记关要烧图：通义一张图有价，买断一次收齐、后面无限生成，会把毛利吃穿。订阅能按月控额度，也方便以后调帽。

### 免费 vs Plus

| | 免费 | Plus 会员 |
|--|------|-----------|
| 官方包 | 完整 **水果森林**（约 **8** 关） | 再解锁自行车 / 机器人 / 英雄 / 小狗 / 钓鱼 / 游泳 |
| 每日时长上限 | **保留现有上限** | 同样保留；会员 **可以** 提高上限（产品以后定） |
| 家庭日记生成 | **1 次 / 月**；不配云端图 | **3 次 / 周**；云端图可选 |
| 加购日记生成 | 无 | 会员可加购 **¥6 / 次**（见第 5 节） |

**锁在哪：** 首页主题包磁贴。未解锁的包对孩子不可点进；价格与「开通」只出现在家长门禁之后。

**钓鱼日第 1 关** 可作为可选试玩（teaser），**不要求** 放进 v1 免费集合。是否做，见第 11 节。

```text
免费今晚
  水果森林整包 + 每日时长帽 + 日记 1 次/月（无云图）

会员今晚
  其余官方包 + 日记 3 次/周（可云图）+ 可选加购生成
```

## 5. 竞品价与本品建议价

下列竞品价为 **2026-09 公开信息摘录**，不是本仓库编造，也不保证商店现价未变。

| 产品 | 公开价（摘录） | 对照 |
|------|----------------|------|
| **洪恩英语**（中国区 App Store） | **¥28 / 月**，**¥268 / 年**，VIP 终身 **¥388**，SVIP **¥568** | 同龄口语 / 动画课；有终身档 |
| **斑马 AI 英语** | 标价约 **¥3200 / 年**，促销常见 **¥2700–2900** | 体系课 + 督学，不是 10 分钟共玩 |
| **Buddy.ai** | **$12.49 / 月**，**$49.99 / 年** | **仅作海外对照**，不是国内对标价 |

**本品建议起步价（不是调研结论）：**

| 档 | 价格 | 折合 |
|----|------|------|
| 包月 | **¥18 / 月** | — |
| 包年 | **¥148 / 年** | 约 **¥12.3 / 月** |
| 会员加购日记生成 | **¥6 / 次** | 仅会员可买 |
| 终身买断 | **不做** | 日记配图有持续成本 |

**双端同价：** iOS 与 Android 都标同一人民币价（¥18 / ¥148）。不要一边 ¥18、一边换算成另一个整数「好看价」。

**自动续费：** 家长页必须写清如何取消（系统订阅管理入口 + 本 App 内说明）。取消后权益用到当期结束；儿童路径始终不出现续费文案。

相对洪恩月/年更低一档，是因为我们卖的是共玩窗口，不是学期课。斑马年价不在同一品类，列出来只为避免把本品误标成「几千一年的体系课」。

## 6. 成本（为什么必须设帽）

| 项 | 公开/清单价 | 对一笔日记的含义 |
|----|-------------|------------------|
| 通义 **wan2.6-t2i** | **¥0.20 / 张**（百炼清单价） | 迷你包常见 **6–10** 张图 → **¥1.2–2.0** |
| DeepSeek 脚本 | 远小于 **¥0.1** / 次 | 相对配图可忽略 |

会员若按 **3 次生成 / 周**、且 **每次都走云端配图**：

```text
3 次/周 × 约 4 周 ≈ 12 次/月
12 × ¥1.2–2.0 ≈ ¥14.4–24 / 月
上限约 ¥24 / 月  >  月费 ¥18
```

所以 **额度必须设帽**。只用相册、不走云端图的生成，**不计入** 配图成本。

上线后跟踪：**每个付费用户每月实际生成次数**、其中几次开了云图。帽不够或毛利为负时，先调次数，再调价。

## 7. 合规与上架前必须面对的事

本文不是法律意见。上架前请律师 / 合规顾问按当时有效条文审。

| 项 | 要求 |
|----|------|
| 谁付钱 | **家长付**；儿童路径无价格、无广告、无诱导付费 |
| 隐私 | 遵守个人信息保护与 **儿童个人信息** 相关规定；能说明采了什么、存在哪、家长怎么删 |
| 年龄分级 | 面向 **4–6 岁**；无社交、无开放闲聊、无 UGC 广场 |
| 主体 | 需要经营主体 + 软件著作权等商店常见材料 |
| 包名 | 上架前把 `com.aienglish.fruitforest` / **Fruit Forest** 改成正式展示名与 bundle id（见第 11 节） |
| 仓库 | 考虑改为私有仓，避免 Key 示例与未发布资源被扫 |
| 商店功能 | **恢复购买** + **账号注销 / 删除** 必须做 |
| Android | v1 **至少先选一家** 国内商店，不要七家同时审 |

## 8. 工程顺序（先权利，后收款）

按这个顺序搭，**不要** 在 1–3 完成前接入真实支付：

1. **权益模型**（家庭 ↔ 会员状态、免费包 / 会员包、日记额度）  
2. **云 Key 改由服务端持有**（家长不再把 Key 贴进手机）  
3. **手机号账号**（登录、登出、注销）  
4. **StoreKit**（iOS IAP、恢复购买）  
5. **微信 / 支付宝**（Android）  
6. **服务端账本**（订单、到账、权益生效 / 过期）  
7. 可选：以后再做云端进度同步  

```text
1 权益 → 2 服务端 Key → 3 手机号
                ↓
        4 StoreKit / 5 微信支付宝
                ↓
              6 账本
                ↓
         7（可选）云进度
```

## 9. 阶段

| 阶段 | 做什么 | 仍不做什么 |
|------|--------|------------|
| **P0** | 本文件：把收费边界写进 `docs/` | 不改 App 代码 |

| **P3** | 真钱：StoreKit + 微信 / 支付宝 + 服务端账本 | 不先做打赏 |
| **P4** | 指标：付费转化、日记生成次数 / 付费用户、云图成本 | — |

**可选 P1.5：** App Store **提交之前**，侧载包可用人工解锁码给内测家庭开会员。提交审核前必须关闭。提交之后解锁付费内容只走 Apple IAP。

## 10. 明确不做（与第 0 节一致）

- 不把 **打赏 / 赞赏码** 当主收入。  
- 儿童路径 **不设付费墙、不插广告、不出现价格**。  
- **提交 App Store 之后**，不用微信转账 + 解锁码卖付费内容。  
- 不做终身买断。  
- 不同时首发海外商店。  
- 不在 1–3（权益 / 服务端 Key / 账号）完成前接线支付。  
- 不把词汇量、CEFR、BBC/牛津、音素打分、儿童开放 LLM 闲聊当卖点。
