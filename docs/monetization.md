## 0. 一页纸

| 项 | 决策 |
|----|------|
| 市场 | **中国大陆先上**；海外以后再说；**不同时双开海内外商店** |
| 形态 | iOS 与 Android **都走官方商店 App**；技术栈继续 **Capacitor + Web**。上架节奏可 **Android 先**（先选一家国内商店），iOS 随后；支付架构不变 |
| 买家 | 卖给 **4–6 岁孩子的家长**；儿童路径上 **不出现价格** |
| 产品 | **每晚约 10 分钟共玩**，不是课程体系 |
| 展示名 | 商店 / 软著 / APP 备案：**土豆豆AI英语**（取代 Fruit Forest） |
| 包名 | **com.tudoudou.aienglish**（取代 `com.aienglish.fruitforest`；工程改名见 P2，本文不改代码） |
| 权益 | **家长订阅 Plus**。免费：首页 **全部** 官方 / 系统主题包与关卡（水果森林、钓鱼、游泳、自行车、机器人、英雄、小狗等整份官方目录）+ 现有每日时长上限。Plus：**只**覆盖每日关卡 / 家庭日记相关生成（会员额度、可选通义云图、可选会员加购）。**官方主题包不再作为会员解锁项** |
| 支付 | **两条支付轨、一份权益**：iOS 走 Apple IAP；Android 走微信 / 支付宝（或国内应用商店代收）。会员资格落在 **服务端**；手机号登录；可跨设备、跨系统恢复 |

**硬规则：** 一旦提交 App Store，解锁付费内容 **必须** 走 Apple IAP。微信 + 解锁码只允许作为 **上架前内测**，审核前必须关掉。

**与竞品文档的边界变化：** [`docs/competitive-analysis.md`](competitive-analysis.md) 曾写「明确不做商业化」。本方案改变该产品方向边界：可以收费，但仍不做完整课程体系、儿童自由聊天、社交或生产级 CMS。

```text
家长付一次 Plus 会员
        │
        ▼
  服务端一份权益 ──► iPhone / Android 平板都能用
        │               （官方包两边都免费；日记生成跟会员走）
   ┌────┴────┐
   │         │
 Apple IAP   微信 / 支付宝（国内 Android 商店）
```

## 1. 现状（对照本仓库）

当前版本 **v0.1.0**。还没有账号，也没有云同步。

| 项 | 现在怎样 |
|----|----------|
| 账号 | 无。进度与日记都在本机 |
| 家长门禁 | 算术题只挡设置页，不是付费门 |
| 家庭日记 Key | DeepSeek / 通义等云 Key **存在本机** |
| Android | Capacitor 8；仓库现用包名仍是 `com.aienglish.fruitforest`、展示名仍是 **Fruit Forest**。上架方向已改为 **土豆豆AI英语** / `com.tudoudou.aienglish`（工程改名属 P2，本文不改代码）。仓库 **没有** `android/`；也 **没有** GitHub Releases。APK 靠本机 Android Studio 打 |
| iOS | 文档写的是 **侧载、不上架**；没有 StoreKit |
| 官方关卡 | 手写 JSON + 静态资源，边际成本接近 **零**；**全部免费开放** |
| 日记关卡 | 每次生成要烧脚本与（可选）配图，**不是** 零边际成本；**这才是 Plus 卖的东西** |

一句话：现在能玩、能侧载，但还不能在商店卖、也不能跨设备认同一份会员。

## 2. 三条可卖的话（只讲这些）

对外只讲这三句（与竞品分析 7.1 对齐）：

1. **说了故事才走**：孩子开口，剧情才往前。  
2. **永不卡死**：认错、害羞、ASR 不准，都可以点图过。  
3. **今晚的生活能变成一关**：官方包保证有得玩（且全部免费）；日记工作室把今天变成可开口关卡（Plus）。

**不要拿来卖的：**

- 词汇量、级别数  
- CEFR / 课标进度  
- BBC / 牛津版权库  
- 音素级打分  
- 儿童与大模型开放闲聊

## 3. 国内双端商店

| 端 | 商店 | 收款 | 说明 |
|----|------|------|------|
| iOS | 中国区 App Store | **必须** Apple IAP | 上架后不能再用微信解锁码卖付费内容 |
| Android | 华为 / 小米 / 应用宝等 | 微信 / 支付宝，或商店代收 | v1 至少先选一家；节奏可 Android 先 |

**权益在服务端。** iPhone 订的会员，同一家长账号在 Android 平板上也生效。客户端只问「这份家庭现在是不是会员」，不问「这笔钱是哪条轨收的」。官方主题包不进这套权益门；会员状态只挡每日关卡 / 家庭日记生成。

**上架前可选：** 侧载包 + 人工解锁码，方便亲友内测。  
**提交 App Store 当天必须关掉** 解锁码通道。之后只走 IAP。

**打赏不是方案。** 不把赞赏码、红包、自愿打赏当成主收入，也不用它绕过商店规则。

## 4. 为什么是订阅，不是买断

日记关要烧图：通义一张图有价，买断一次收齐、后面无限生成，会把毛利吃穿。订阅能按月控额度，也方便以后调帽。官方主题包边际成本接近零，**不拿来当会员锁**。

### 免费 vs Plus

| | 免费 | Plus 会员 |
|--|------|-----------|
| 官方 / 系统主题包 | **全部开放**：水果森林、钓鱼、游泳、自行车、机器人、英雄、小狗等首页整份官方目录与关卡 | 同样全部开放；**不再**把官方包当解锁项 |
| 每日时长上限 | **保留现有上限** | 同样保留；会员 **可以** 提高上限（产品以后定） |
| 每日关卡 / 家庭日记生成 | **默认无会员额度**。可选偏好（建议、非必须）：每月 **1 次** 日记生成、**不配云端图**，作试玩 | **会员额度**（建议 **3 次 / 周**，是否够用见第 11 节）；通义云端图可选 |
| 加购日记生成 | 无 | 会员可加购 **¥6 / 次**（见第 5 节） |

**锁在哪：** 「每日关卡 / 家庭日记」入口，**不是**首页主题包磁贴。官方包对孩子全部可点进；日记生成相关入口才问会员。价格与「开通」只出现在家长门禁之后。儿童路径始终不出现价格。

```text
免费今晚
  全部官方主题包（水果森林、钓鱼、游泳、自行车、机器人、英雄、小狗等）
  + 现有每日时长帽
  +（可选偏好）日记 1 次/月（无云图）

Plus 今晚
  同样全部官方包
  + 每日关卡 / 家庭日记：会员额度（可云图）+ 可选加购生成
```

```text
首页主题包磁贴 ──► 全部可进（免费）

每日关卡 / 家庭日记入口
        │
        ▼
  家长门禁之后才出现价格 / 开通
        │
   ┌────┴────┐
   │         │
  有额度     无额度 → 引导开通 Plus
```

## 6. 成本（为什么必须设帽）

| 项 | 公开/清单价 | 对一笔日记的含义 |
|----|-------------|------------------|
| 通义 **wan2.6-t2i** | **¥0.20 / 张**（百炼清单价） | 迷你包常见 **6–10** 张图 → **¥1.2–2.0** |
| DeepSeek 脚本 | 远小于 **¥0.1** / 次 | 相对配图可忽略 |

会员若按 **3 次生成 / 周**、且 **每次都走云端配图**：

```text
3 次/周 × 约 4 周 ≈ 12 次/月
12 × ¥1.2–2.0 ≈ ¥14.4–24 / 月
上限约 ¥24 / 月  >  月费 ¥18
```

所以 **额度必须设帽**。只用相册、不走云端图的生成，**不计入** 配图成本。官方主题包不烧云图，**不进这本账**。

上线后跟踪：**每个付费用户每月实际生成次数**、其中几次开了云图。帽不够或毛利为负时，先调次数，再调价。

## 8. 工程顺序（先权利，后收款）

按这个顺序搭，**不要** 在 1–3 完成前接入真实支付：

1. **权益模型**（家庭 ↔ 会员状态、日记额度；官方主题包全部免费，不再分「免费包 / 会员包」）  
2. **云 Key 改由服务端持有**（家长不再把 Key 贴进手机）  
3. **手机号账号**（登录、登出、注销）  
4. **StoreKit**（iOS IAP、恢复购买）  
5. **微信 / 支付宝**（Android）  
6. **服务端账本**（订单、到账、权益生效 / 过期）  
7. 可选：以后再做云端进度同步  

```text
1 权益（日记额度，不是官方包锁）
        → 2 服务端 Key → 3 手机号
                ↓
        4 StoreKit / 5 微信支付宝
                ↓
              6 账本
                ↓
         7（可选）云进度
```

## 10. 明确不做（与第 0 节一致）

- 不把 **打赏 / 赞赏码** 当主收入。  
- 儿童路径 **不设付费墙、不插广告、不出现价格**。  
- **提交 App Store 之后**，不用微信转账 + 解锁码卖付费内容。  
- 不做终身买断。  
- 不同时首发海外商店。  
- 不在 1–3（权益 / 服务端 Key / 账号）完成前接线支付。  
- 不把词汇量、CEFR、BBC/牛津、音素打分、儿童开放 LLM 闲聊当卖点。  
- **不再**把官方主题包当会员解锁项。
