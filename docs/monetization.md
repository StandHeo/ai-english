## 3. 国内双端商店

| 端 | 商店 | 收款 | 说明 |
|----|------|------|------|
| iOS | 中国区 App Store | **必须** Apple IAP | 上架后不能再用微信解锁码卖付费内容 |
| Android | 华为 / 小米 / 应用宝等 | 微信 / 支付宝，或商店代收 | v1 至少先选一家；节奏可 Android 先 |

**会员资格可以在服务端。** iPhone 订的 Plus，同一家长账号在 Android 平板上也生效。客户端问「这份家庭现在是不是 Plus」，不问「这笔钱是哪条轨收的」。官方主题包不进这套门；Plus 状态只挡家庭日记 / 每日关卡工作室。

**LLM Key 不在这套门里。** 服务端认的是订阅，不是供应商账号。日记生成用家长本机 Key，直连 Agnes / DeepSeek / 通义等；v1 **没有**一份「公司垫付的共享云 Key」。

**上架前可选：** 侧载包 + 人工解锁码，方便亲友内测。  
**提交 App Store 当天必须关掉** 解锁码通道。之后只走 IAP。

**打赏不是方案。** 不把赞赏码、红包、自愿打赏当成主收入，也不用它绕过商店规则。

## 4. 为什么是订阅，不是买断

Plus 卖的是 **工作室使用权 + 持续打磨的配置向导**，方便跨设备恢复会员资格，也方便以后改向导体验。它 **不是** 代付 token 的流量包，因此也 **不按次加购生成**。

v1 **不做买断终身**：要持续改向导与权益恢复，买断会把后续改版绑死。理由 **不是**「我们要扛配图账单」——BYOK 下那笔账在家长与供应商之间。

官方主题包边际成本接近零，**不拿来当会员锁**。

### 免费 vs Plus

| | 免费 | Plus 会员 |
|--|------|-----------|
| 官方 / 系统主题包 | **全部开放**：水果森林、钓鱼、游泳、自行车、机器人、英雄、小狗等首页整份官方目录与关卡 | 同样全部开放；**不再**把官方包当解锁项 |
| 每日时长上限 | **保留现有上限** | 同样保留；会员 **可以** 提高上限（产品以后定） |
| 家庭日记 / 每日关卡工作室 | **默认锁定**。可选偏好（建议、非必须）：极短试玩 / teaser，见第 11 节 | **解锁工作室** + **更好的模型配置向导** |
| 日记 AI 算力 | 无（工作室未开） | **不含**。家长 BYOK；生成次数受家长所选供应商约束（如 Agnes 免费档速率 / 余额）。**不再**把「3 次 / 周」当硬权益帽 |
| 加购日记生成 / token 包 | 无 | **v1 不卖**（那会变成代付算力，属于方案 B） |

**锁在哪：** 「每日关卡 / 家庭日记」工作室入口，**不是**首页主题包磁贴。官方包对孩子全部可点进；工作室才问 Plus。价格与「开通」只出现在家长门禁之后。儿童路径始终不出现价格。

**生成次数：** Plus 打开工作室后，能生成几次主要由家长的供应商决定（推荐 Agnes 免费档作为入门路径）。本品 **可以** 以后加软性产品限速（体验 / 防刷），那不是为了控自己的 LLM 账单。硬额度是否要做，见第 11 节；v1 **不**把「3 次 / 周」写成 Plus 标配权益。

Plus 今晚

## 6. 成本（BYOK 下日记生成 COGS ≈ 0）

v1 日记生成 **不走** 公司固定共享 Key。每次脚本 / 配图调用打到家长自己的供应商账号。因此：

| 谁 | 日记生成成本 |
|----|----------------|
| **本品（土豆豆）** | **COGS ≈ 0**（不垫付 token、不持有共享 LLM Key） |
| **家长** | 向所选供应商付费或占用免费档。推荐入门：**Agnes 免费档**（当前家庭日记设置已支持；速率以对方为准，文档曾记免费档约 20 次 API/分钟量级） |

家长侧可能看到的公开价（**不是本品 COGS**，只帮助向导说明「选谁会花钱」）：

| 供应商 | 公开/清单价（摘录） | 家长侧含义 |
|--------|---------------------|------------|
| **Agnes**（推荐默认） | 免费档 / 活动价以对方为准 | **推荐入门路径**：先走免费档把今晚关做出来 |
| DeepSeek 脚本 | 远小于 **¥0.1** / 次量级 | 家长自备 Key 时的可选脚本模型 |
| 通义 **wan2.6-t2i**（百炼） | **¥0.20 / 张** 清单价 | 迷你包常见 **6–10** 张图 → 家长侧约 **¥1.2–2.0** / 次；可改 Agnes 图或相册 |

旧账「会员 3 次/周 × 通义配图 ≈ ¥14–24 / 月 > 月费 ¥18，所以必须设帽」**作废**。那是假设 **我们** 持有云 Key、为我们的账单设帽。纯 A 下没有这笔公司账单，也就 **不必** 用「3 次 / 周」当 Plus 硬权益。

上线后跟踪的是：**Plus 转化**、**向导是否配完 Key**、**生成成功率**、家长选了哪家供应商。不要把「每付费用户云图成本」当成 v1 毛利主指标——那笔钱不是我们付的。

**方案 B（后期，不在 v1）：** 若以后改为服务端托管 Key / 出售额度，才重新出现本品 COGS，才需要次数帽与加购。本文不把方案 B 写成上架前置。

## 8. 工程顺序（先会员资格，后收款；LLM Key 不是支付前置）

按这个顺序搭，**不要** 在会员资格模型与家长账号完成前接入真实支付。

**会员资格（商店订阅）与 LLM Key（BYOK）分开：**

1. **权益模型**（家庭 ↔ Plus 状态、工作室锁定 / 解锁；官方主题包全部免费。**不是**「免费包 / 会员包」，也 **不是** 日记次数账本）  
2. **家长账号**（当前：**邮箱验证码**登录、登出、注销；用来认 Plus、恢复购买。生产发信走腾讯云 SES **API**，个人实名不能 SMTP。短信登录代码保留，待资质后再开）  
3. **StoreKit**（iOS IAP、恢复购买）  
4. **微信 / 支付宝**（Android）  
5. **服务端账本**（订单、到账、Plus 生效 / 过期）  
6. 可选：以后再做云端进度同步  
7. **方案 B（后期 / 不在 v1）：** 服务端托管共享 Key、代付 token、次数帽与加购  

工作室配置向导（帮家长注册 Agnes 免费档、粘贴 Key、测通）属于 **Plus 体验**，在客户端做；**不**等于「云 Key 改由服务端持有」。后者 **不是** P0，也 **不是** 接线支付的前置步骤。

```text
1 权益（工作室锁，不是官方包锁，也不是 token 帽）
        → 2 邮箱账号（认 Plus；短信备后用）
                ↓
        3 StoreKit / 4 微信支付宝
                ↓
              5 账本
                ↓
         6（可选）云进度

日记 LLM：本机 BYOK（与上列并行，不挡支付）
方案 B 托管 Key / 额度：后期，不在 v1
```
