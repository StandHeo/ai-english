# 家长视角体验笔记（4 岁共玩）

> 站在「4 岁孩子的妈妈」视角审视当前 App：英语启蒙 / 共玩体验。  
> **本文只记录洞察与待定，不代表已排期实现。**  
> 下次继续时：优先看文末 **「待定 · 下次继续聊」**。

关联：`docs/tech-architecture.md`、`docs/beep-tail-talk.md`、`openspec/changes/kids-story-oral-english-mvp/`（尤其 `child-play-ux`、`progress-rewards`）。

---

## 1. 使用情境（默认镜头）

- 晚上约 10 分钟窗口；孩子刚洗完澡，注意力有限。
- 妈妈目标不是「刷完包」，而是：**顺利玩完一小关，让孩子觉得英语好玩。**
- 成功标准：来得及鼓掌、指认贴纸、愿意明天再打开——不是功能清单完整。

```text
理想共玩闭环

选关 → 听 / 找 / 说 → 通关贴纸仪式（结算）→ （可选 Beep）→ 点 ▶ 再继续
         ↑                      ↑
    成功率要高              奖赏要被看见
```

## 2. 总览：已对的地方 & 主要缝隙

### 2.1 已经对的

- 儿童路径骨架清楚：`听 → 找 → 说 → 贴纸/星星`；点图兜底，故事倾向「永不卡死」。
- 主题包丰富（水果、自行车、机器人、英雄、小狗、钓鱼、游泳等），短词关（apple / dog / pool）很适合启蒙。
- 家长侧有门禁、日记 → 生成今日关、日历囤关——方向亲子，不是纯刷题。
- 日记语音已改为 IndexedDB + 更长上限与倒计时（见 `docs/family-diary-whisper.md`）。
- 官方关已普遍配置 `beep_talk`（见 `docs/beep-tail-talk.md`）。

### 2.2 主要缝隙（按妈妈优先级）

| 优先级 | 缝隙 | 一句话 |
|--------|------|--------|
| P0 | 通关仪式弱（**现状**） | **已定 T1=α**：中等仪式 + 点 ▶；**不要**自动连玩；**代码未改** |
| P0 | 缺首次共玩引导 | 「今晚怎么带他玩」在文档里，不在开屏里 |
| P1 | 听窗 / 失败节奏 | ~3.5s 偏紧；易学会「乱说再点图」 |
| P1 | Beep 挡在贴纸前（**现状**） | **已定 T7=D**：改为贴纸后可选；**代码未改** |
| P1 | 家长工作室心智重 | Key / API / 关键词阈值像工程配置 |
| P2 | 每日限额无友好说明 | 地图变暗易被当成坏了 |
| P2 | 进度 / 隐私不够一眼安心 | 清数据会丢；Key 在本机但 App 内少提示 |

## 3. 儿童路径现状（锚点）

```text
首页主题图 → 地图关卡点 → beats（introduce / find / ask）
                              → beep_talk（多数官方关）
                              → finishLevel：发贴纸 + TTS「Yay!」+ ~1.2s 自动跳下一关
贴纸墙：/stickers 格子亮/灰（与通关时刻弱连接）
```

实现锚点（便于改时对照，非任务清单）：

- 通关：`apps/web/src/pages/LevelPage.tsx` → `finishLevel`（约 1.2s 后 `navigate`）
- 拍内短庆祝：`result-flash` / `burst`（约 0.7s）
- 听窗：主线 `LISTEN_MS = 5000`（`usePressToTalk.ts`）；Beep `BEEP_LISTEN_MS = 5000`
- 贴纸墙：`StickersPage.tsx`（支持「今晚新得」高亮）
- 首次共玩：`CoplayIntroCard`（首页，仅一次）
- 规格张力：儿童主路径少中文；调试态藏在「·」面板（T18）

## 4. 孩子侧深挖（线索 A · 已细聊部分）

### 4.1 通关仪式（**T1=α · T2=α 已拍板**）

**问题：** 拍内有「太棒了」，整关通关反而更空；贴纸未成为第一视觉。

**产品决策（2026-08-13，尚未改代码）：**

| 编号 | 决策 |
|------|------|
| **T1 = α′** | 仪式「中等」：大贴纸 + Yay；播完短停留后**自动下一关**；▶ 可提前；**不要**家长「自动连玩」开关 |
| **T2 = α** | 主行动 = **居中大圆 ▶**（非全宽长条）；仪式上**不放** 🗺️；回地图只用**左上角退出**，并带**轻确认**（✓/✕ 纯图标） |
| （T6） | 「重」仪式**明确二期**（已拍板） |
| **T4** | ~~永不自动跳~~ → 试玩后改为：**语音后约 2.4s 自动下一关**；久等仍可 pulse ▶ |
| **T5** | 图兜底：`stickerImage` → 主词/物品图 → 星星占位 |

**原则：**

1. 贴纸必须是第一视觉（用 `reward.stickerImage`）
2. 够妈妈和孩子一起喊一声（约 2.5–4 秒有内容）
3. **默认自动进下一关**；▶ 仅作提前跳过；回地图走退出且轻确认

**建议时间轴：**

| 时刻 | 行为 |
|------|------|
| 0.0s | 主线结束（T7=D 下此时进仪式）；背景略压暗 |
| ~0.2s | 本关贴纸「砰」出现在中央 |
| ~0.4s | TTS：**T3 = B+C**（见下）；单句，不连播两句 |
| 0.5–2.5s | 轻 bounce + 可复用 burst |
| ≥2.5s | **居中大圆 ▶** 出现；**等待点击**（无自动跳） |
| 点 ▶ | 短过渡进下一关（Beep 未玩则跳过，见 T7c） |
| 点左上退出 | 轻确认 → 回地图 |

**通关 TTS（T3 = B+C，已拍板）：**

欢呼轮换（B）+ 贴关主词（C）合成**一句**，例如：

| 模板 | 例子 |
|------|------|
| 默认 | `{Cheer}! {Word}!` → `Yay! Apple!` / `Wow! Bike!` |
| Cheer 池 | 复用现有感：`Yay` / `Wow` / `Great` / `Super`（`Yum` 仅水果等合适主题可用，实现时可简单轮换前四个） |
| Word | `target_words[0]`（或多词关的贴纸主词）；首字母大写 |
| 无主词 / 异常 | 退回单句 Cheer：`Yay!` |

- **一期不做**两句连播（`Yay!` 再 `Apple sticker!`）  
- **一期不做**必须念 `sticker` 一词（`Apple sticker!` 可作二期变体；默认用更短的 `{Cheer}! {Word}!`）  
- 运行时拼接即可，不必先给 59 关手写 `celebrate_say`

**画面意象（T2=α · T7a=α）：**

```text
┌  exit（左上） ─────────────┐
│  ░ 场景压暗 ░               │
│         ╭─────╮             │
│         │ 贴纸 │            │
│         ╰─────╯             │
│            ★                │
│          ( ▶ )              │  ← 唯一主按钮：居中大圆
│                     [🤖]    │  ← 次：小 Beep（仅有 beep_talk 时）
└─────────────────────────────┘
  退出轻确认：  [✓]   [✕]
```

竖屏优先大圆（约 ≥72–88px）；矮横屏若点不准，实现可退化为底栏全宽 ▶，**产品语义仍是「单一主行动」**。

儿童路径尽量纯图标。若日后有「中文辅助」家长开关，再显示「下一关」等文案（待定）。

**与拍内庆祝区分：**

| | 拍成功 | 通关 |
|--|--------|------|
| 节奏 | 保持短 flash | 专用通关层；语音后短停留**自动下一关**（▶ 可提前） |
| 视觉 | ✓ / 短文案 | 大贴纸登场 |

**三种强度（当前默认「中 + 自动」）：**

| 强度 | 行为 | 当前 |
|------|------|------|
| 轻（纯闪） | 贴纸闪后立刻跳 | 不做 |
| **中 + 自动** | 大贴纸 + Yay，播完约 2.4s **自动下一关**；▶ 可提前；🤖 仍可点 Beep（会取消自动） | **默认** |
| 重 | 中 + 飞入贴纸墙 | 二期候选（T6） |

**已倾向的偏好（细节仍可在 T3–T5 微调）：**

- 首次 / 重复通关可先同一套 UI，重复关少一点动效即可
- 仪式层干净；Beep 入口见 **T7a=α**（小头像，不得与大圆 ▶ 同等大）
- ~~久等仅 pulse、永不自动跳~~ → **试玩反馈后改为自动下一关**（仍保留 ▶ / Beep）
- 通关语音见 **T3=B+C**

### 4.2 关长与 Beep（**T7=D · T7a=α 已拍板**）

- Beep 可爱，但叠在主线后等于「一关半」；关尾若再难词 + 短庆祝，情绪易垮。
- **产品决策（2026-08-13，尚未改代码）：**
  - **T7 = D**：贴纸仪式在前并结算；Beep 为可选项
  - **T7a = α**：仪式右下（或贴纸右下外侧）**小 Beep 头像**次按钮；聊完**回到仪式**（再点 ▶ 离开）

```text
目标体验（T7=D + T7a=α）

主线 beats 结束
        │
        ▼
  通关贴纸仪式（结算贴纸）
        │
        ├─ （默认）语音后短停留 ──▶ 自动下一关 / 地图
        ├─ 大圆 ▶ ──▶ 提前下一关 / 地图（未点 Beep = 跳过）
        │
        └─ 小 🤖 ──▶ Beep 对话 ──▶ 回到仪式（再自动 / 可点 ▶）
```

**T7a=α 细则：**

| 项 | 约定 |
|----|------|
| 尺寸 | 约大圆 ▶ 的 40–50%，低对比，非主色大块 |
| 位置 | 右下 / 贴纸右下外侧；**不与 ▶ 同一水平抢拇指** |
| 出现 | 与 ▶ 同时可点（不延迟隐藏） |
| 无 `beep_talk` | 不渲染 🤖 |
| 聊完 | **回仪式**，随后再次自动下一关（或点 ▶） |
| 点 ▶ | 不进 Beep（与 T7c 倾向一致：静默跳过） |
| Beep 中途退出 | 回仪式或回地图（轻确认）；**不扣已发贴纸** |

**相对现状的语义变化（实现时必须对齐）：**

| | 现状（代码） | 决策 D（目标） |
|--|-------------|----------------|
| 贴纸发放时机 | Beep 全部走完后 | **主线结束进入仪式时** |
| Beep 中途退出 | 不发贴纸、不记通关 | Beep 为加料；**退出不扣已发贴纸** |
| 无精力时 | 仍必须熬完 Beep 才见奖 | 可先拿贴纸，点 ▶ 离开 |

仍开着（内容侧）：难词坡道等见 §8。节点数与跳过已定：**T7b=保持 3 节点**；**T7c=点 ▶ 静默跳过 Beep**；**T8=一期不做**「总是先 Beep」开关。


### 4.3 听窗与失败节奏（细则部分待定）

- 主线 ~3.5s 对 4 岁偏紧（看妈妈 → 笑 → 再开口）。
- 「永不卡死」正确；若点图过易、说话窗过短，会强化捷径学习。
- 方向候选：听窗接近 Beep；首次失败先再听示范；点图时仍播目标词——**未选定**（T9–T11）。
- **已落地（家长反馈）**：对了用设计成功音效（+ 短成功句）；错了只用短促「嘟嘟嘟」SFX，**不再**播 `Nice try!` 类鼓励 TTS——孩子会故意选错刷好玩的声音。
- **已落地**：选对时偶尔叠一段轻庆祝短曲（Web Audio，非每次；至少隔几次成功 + 冷却后再随机）。

### 4.4 难词坡道（已分析，细则待定）

- 甜：apple、dog、fish、pool、ring、bike…
- 涩：mountain bike、tricycle…（游泳包已改为 kick / water / fish 等短词）
- `goggles` 仍略长，识别接受 `glasses` 近似。
- 方向候选：地图标记「大一点再玩」、难关更短 Beep / 更松 expect——**未选定**。

### 4.5 贴纸墙（轻量结论）

- 通关仪式若做好，墙可继续朴素。
- 仪式若仍短，墙至少应支持「今晚新得」高亮（待定是否做）。

## 5. 其它线索（仅总览，细聊在待定）

### 5.1 线索 B · 家长「今晚一关」

日记 → DeepSeek 生成很有爱，但路径含 Key、局域网 API、关键词阈值、配图开关等，像工作室不像「晚饭后三步」。  
目标感：**说一句今天的事 → 生成 → 和孩子点开玩**。

### 5.2 线索 C · 产品叙事 / 首次共玩

缺开屏：「今晚先玩水果第 1 关；听不懂看图；说不出点图；通关看贴纸。」  
每日限额需人话：「今天英语冒险玩够啦，明天再来～」

### 5.3 线索 D · 年龄分层

4 岁默认：中等通关仪式（T1=α）+ 贴纸后可选 Beep（T7=D）+ 甜词优先；年龄显式分层见 T21（**不再**把「自动连玩」当作默认配套）。
