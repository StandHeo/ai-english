# 家长视角体验笔记（4 岁共玩）

> 站在「4 岁孩子的妈妈」视角审视当前 App：英语启蒙 / 共玩体验。  
> **本文只记录洞察与待定，不代表已排期实现。**  
> 下次继续时：优先看文末 **「待定 · 下次继续聊」**。

关联：`docs/tech-architecture.md`、`docs/beep-tail-talk.md`、`openspec/changes/kids-story-oral-english-mvp/`（尤其 `child-play-ux`、`progress-rewards`）。

---

## 1. 使用情境（默认镜头）

- 晚上约 10 分钟窗口；孩子刚洗完澡，注意力有限。
- 妈妈目标不是「刷完包」，而是：**顺利玩完一小关，让孩子觉得英语好玩。**
- 成功标准：来得及鼓掌、指认贴纸、愿意明天再打开——不是功能清单完整。

```text
理想共玩闭环

选关 → 听 / 找 / 说 → （可选 Beep）→ 看见贴纸仪式 → 点一下再继续
         ↑                                    ↑
    成功率要高                           奖赏要被看见
```

---

## 2. 总览：已对的地方 & 主要缝隙

### 2.1 已经对的

- 儿童路径骨架清楚：`听 → 找 → 说 → 贴纸/星星`；点图兜底，故事倾向「永不卡死」。
- 主题包丰富（水果、自行车、机器人、英雄、小狗、钓鱼、游泳等），短词关（apple / dog / pool）很适合启蒙。
- 家长侧有门禁、日记 → 生成今日关、日历囤关——方向亲子，不是纯刷题。
- 日记语音已改为 IndexedDB + 更长上限与倒计时（见 `docs/family-diary-whisper.md`）。
- 官方关已普遍配置 `beep_talk`（见 `docs/beep-tail-talk.md`）。

### 2.2 主要缝隙（按妈妈优先级）

| 优先级 | 缝隙 | 一句话 |
|--------|------|--------|
| P0 | 通关仪式弱 | 贴纸进了数据，几乎没进「被看见的一刻」 |
| P0 | 缺首次共玩引导 | 「今晚怎么带他玩」在文档里，不在开屏里 |
| P1 | 听窗 / 失败节奏 | ~3.5s 偏紧；易学会「乱说再点图」 |
| P1 | Beep + 难词拉长关尾 | 完整度好，4 岁易腻 / 挫败 |
| P1 | 家长工作室心智重 | Key / API / 关键词阈值像工程配置 |
| P2 | 每日限额无友好说明 | 地图变暗易被当成坏了 |
| P2 | 进度 / 隐私不够一眼安心 | 清数据会丢；Key 在本机但 App 内少提示 |

## 3. 儿童路径现状（锚点）

```text
首页主题图 → 地图关卡点 → beats（introduce / find / ask）
                              → beep_talk（多数官方关）
                              → finishLevel：发贴纸 + TTS「Yay!」+ ~1.2s 自动跳下一关
贴纸墙：/stickers 格子亮/灰（与通关时刻弱连接）
```

实现锚点（便于改时对照，非任务清单）：

- 通关：`apps/web/src/pages/LevelPage.tsx` → `finishLevel`（约 1.2s 后 `navigate`）
- 拍内短庆祝：`result-flash` / `burst`（约 0.7s）
- 听窗：主线 `LISTEN_MS ≈ 3500`（`usePressToTalk.ts`）；Beep `BEEP_LISTEN_MS = 5000`
- 贴纸墙：`StickersPage.tsx`（无「今晚新得」高亮）
- 规格张力：`child-play-ux` 要求儿童路径少依赖中文；现网关卡内仍有中文 tip / 调试态文案

## 4. 孩子侧深挖（线索 A · 已细聊部分）

### 4.1 通关仪式 —— 建议默认「中等强度」

**问题：** 拍内有「太棒了」，整关通关反而更空；贴纸未成为第一视觉。

**原则：**

1. 贴纸必须是第一视觉（用 `reward.stickerImage`）
2. 够妈妈和孩子一起喊一声（约 2.5–4 秒有内容）
3. 4 岁默认：**点 ▶ 才进下一关**（不要 1.2s 抢走时刻）

**建议时间轴：**

| 时刻 | 行为 |
|------|------|
| 0.0s | Beep / 末拍结束；背景略压暗 |
| ~0.2s | 本关贴纸「砰」出现在中央 |
| ~0.4s | TTS：`Yay!`（或更贴关的短句，待定） |
| 0.5–2.5s | 轻 bounce + 可复用 burst |
| ≥2.5s | 超大热区 ▶；可选小 🗺️ 回地图；**等待点击** |
| 点击后 | 短过渡进入下一关或地图 |

**画面意象：**

```text
░ 场景压暗 ░
      ╭─────╮
      │ 贴纸 │  ← 本关 reward 大图
      ╰─────╯
        ★ +1
   [  大 ▶  ]     小 🗺️
```

儿童路径尽量纯图标（符合少中文规格）。若日后有「中文辅助」家长开关，再显示「下一关」等文案（待定）。

**与拍内庆祝区分：**

| | 拍成功 | 通关 |
|--|--------|------|
| 节奏 | 保持短 flash | 专用通关层 + 等待点击 |
| 视觉 | ✓ / 短文案 | 大贴纸登场 |

**三种强度（已倾向「中」为 4 岁默认）：**

| 强度 | 行为 | 适合 |
|------|------|------|
| 轻 | 贴纸闪 1.5–2s，仍自动下一关 | 会刷关的 5–6 岁 |
| **中（建议默认）** | 大贴纸 + Yay + 点 ▶ 才继续 | **4 岁共玩** |
| 重 | 中 + 贴纸飞入收藏入口 | 周末 / 第一次；可二期 |

**已倾向的偏好（仍可在待定里翻案）：**

- 首次 / 重复通关可先同一套 UI，重复关少一点动效即可
- Beep 结束后切到干净通关层，不要叠在 Beep 面板上
- 久等（如 20–30s）可 pulse ▶，仍不强制自动跳

### 4.2 关长与 Beep（已分析，细则待定）

- Beep 可爱，但叠在主线后等于「一关半」；关尾若再难词 + 短庆祝，情绪易垮。
- 方向候选：短关模式（无 Beep / 仅 2 节点）、难关减负、Beep 改为贴纸后的可选打招呼——**未选定**。

### 4.3 听窗与失败节奏（已分析，细则待定）

- 主线 ~3.5s 对 4 岁偏紧（看妈妈 → 笑 → 再开口）。
- 「永不卡死」正确；若点图过易、说话窗过短，会强化捷径学习。
- 方向候选：听窗接近 Beep；首次失败先再听示范；点图时仍播目标词——**未选定**。

### 4.4 难词坡道（已分析，细则待定）

- 甜：apple、dog、fish、pool、ring、bike…
- 涩：breaststroke、backstroke、mountain bike、tricycle、goggles…
- `butterfly` 有心智锚，相对可接受。
- 方向候选：地图标记「大一点再玩」、难关更短 Beep / 更松 expect——**未选定**。

### 4.5 贴纸墙（轻量结论）

- 通关仪式若做好，墙可继续朴素。
- 仪式若仍短，墙至少应支持「今晚新得」高亮（待定是否做）。

## 5. 其它线索（仅总览，细聊在待定）

### 5.1 线索 B · 家长「今晚一关」

日记 → DeepSeek 生成很有爱，但路径含 Key、局域网 API、关键词阈值、配图开关等，像工作室不像「晚饭后三步」。  
目标感：**说一句今天的事 → 生成 → 和孩子点开玩**。

### 5.2 线索 C · 产品叙事 / 首次共玩

缺开屏：「今晚先玩水果第 1 关；听不懂看图；说不出点图；通关看贴纸。」  
每日限额需人话：「今天英语冒险玩够啦，明天再来～」

### 5.3 线索 D · 年龄分层

4 岁默认短关 / 中等仪式 / 甜词优先；5–6 岁可完整 Beep + 可选自动连玩。
