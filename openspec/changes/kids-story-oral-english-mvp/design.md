## 背景

仓库 `ai-english` 目前几乎是空的，仅有 OpenSpec，尚无应用代码。产品动机与 MVP 范围见 `proposal.md`。实现者更熟悉后端与 HTML，不熟原生移动端；首发 Android，后续用同一套代码做 iOS。儿童语音识别噪声大，产品成败更依赖「脚本期望词表 + 兜底」，而非开放语义理解。

## 目标 / 非目标

**目标：**

- 建立可在 Android 上跑通「故事关卡 + 语音回合」的客户端/服务端架构。
- 关卡内容数据驱动（JSON/YAML 脚本），手写关卡包无需为每关改代码。
- 经后端代理 ASR/TTS（以及可选的、受限的 LLM 改写），便于保管密钥、做日志与安全约束。
- 优先走 Web 技术栈，便于发挥 HTML/JS 能力，再打包装成可安装 App。
- MVP 进度本地持久化（日后可再加轻量同步）。

**非目标：**

- MVP 不做 Kotlin/Swift 双端原生两套。
- 不做生产级 CMS、AI 自动上架无审核、多孩云账号体系。
- 不做端侧离线全量 ASR/TTS。
- 不做商业化、完整分析套件，或超出内测安装包之外的商店打磨。

## 决策

### D1 — 客户端：优先 Capacitor（Web），Expo 作备选

- **选择：** 用 React 或 Vue 做儿童/家长 UI，经 **Capacitor** 打 Android APK。若麦克风/TTS 插件或性能卡住验证，再评估 **Expo/React Native**。
- **原因：** 从 HTML 技能到可安装 Android App 路径最短；同一 UI 利于后续 iOS。
- **备选：** 纯 PWA（安装与麦克风体验弱）；Flutter（新语言成本）；直接 RN/Expo（原生感更好，但若不熟 RN 更陡）。

### D2 — 后端保管 AI/语音凭证

- **选择：** App 将音频发到 **自有 API**（或仅使用后端签发的短时令牌），由后端调用云端 ASR/TTS。可选 LLM 只在节拍意图内改写 NPC 台词——绝不开放儿童自由聊。
- **原因：** 密钥安全、统一期望匹配后处理、集中内容安全策略。
- **备选：** 客户端直连厂商 SDK（尖刺更快，密钥与泄露风险更大）。

### D3 — 关卡运行时 = 脚本解释器

- **选择：** 一个通用关卡播放器消费已审核脚本（`id`、`theme`、`target_words`、`beats[]`，含 `type`、`npc_say`、`expect[]`、`hint_say`、`fallback`、`reward`）。
- **原因：** 加关卡不必发新 UI 代码；日后 AI 生成同一 schema，人工审批即可。
- **备选：** 每关硬编码页面（首日演示快，到第 6 关就崩）。

### D4 — 匹配策略：期望词表 + 规范化

- **选择：** 规范化 ASR 文本（小写、去标点）；任一条 `expect` 相等或在简单词边界规则下命中即成功；可按关卡加极小同义表。MVP 不做开放语义打分。
- **原因：** 对孩子可预期；ASR 不准时仍可用；与故事节拍对齐。
- **备选：** 每句都用 LLM 评判（延迟/成本/不可控）；音素评分（过重）。

### D5 — 交互：按住说话

- **选择：** 口语拍用大型按住说话；自动 VAD 延后。
- **原因：** 4–6 岁需要清晰的「我正在说」反馈；减少误判说完。
- **备选：** 始终聆听 + VAD（调好更爽，室内更难）。

### D6 — 进度存储：本地优先

- **选择：** 解锁、通关、贴纸、当日游玩秒数存在设备上（SQLite/Preferences）。家长时长限制 MVP 在客户端执行；后端档案可选。
- **原因：** 无账号也能家庭试玩。云同步可后加，不必改儿童 UX 契约。
- **备选：** 第一天就强制账号（拖慢验证）。

### D7 — 沉浸分层

- **选择：** 儿童界面：图标/动画/英语音频。家长界面：可用中文 + 成人门禁。
- **原因：** 满足全英沉浸，同时不挡家长看管。

### D8 — MVP 内容包

- **选择：** 主题定为 **水果森林 Fruit Forest**，向导 **Bunny**，八关线性（苹果→香蕉→橘子→葡萄→草莓→西瓜→梨→野餐复习），每关一张贴纸。剧情详见 `content/fruit-forest-story.md`（变更目录内）与仓库 `content/levels/*.json`。
- **原因：** 足够验证「还想再玩」，不必先建内容工厂；可在同一主题内加关而不改运行时。

## 风险 / 权衡

- **[风险] 儿童 ASR 准确率低** → 缓解：短目标词、期望变体、两次示范、点图兜底、永不硬卡。
- **[风险] 语音延迟破坏节奏** → 缓解：脚本台词预缓存 TTS；选快速 ASR；UI 动画覆盖 ≤1s；尖刺里量 p95。
- **[风险] Capacitor 在 Android 上麦克风不稳** → 缓解：真机尽早尖刺录音→上传→ASR；卡住则改 Expo。
- **[风险] 全英让部分家庭受挫** → 缓解：强视觉支架 + 家长可见进度；家长英文字幕开关属后续实验，非 MVP 默认。
- **[风险] 范围膨胀成自由聊 / 大世界** → 缓解：规格禁止无约束聊天；地图保持单主题线性节点，不加开放世界。
- **[权衡] 仅本地进度** → 演示容易，多设备弱；验证期可接受。

## 演进计划

1. 搭脚手架：`apps/web` + `apps/api` + `content/levels`。
2. 尖刺：Android APK 录音并经 API 走通 ASR。
3. 实现脚本播放器 + 水果森林关卡包；若在线 TTS 慢可用预录音频。
4. 加奖励与家长门禁/时长。
5. 内部家庭试玩；根据真实转写调期望词表。
6. 之后：Capacitor iOS；可选账号/同步；AI 脚本生成器挂在 `approved` 开关后。

内容回滚：回退到上一版已审核内容包；ASR 故障时可用功能开关切到「仅点选」。
