## 为什么

家庭日记与每日关卡、尤其是语音录音，全部存在本机 WebView（localStorage + IndexedDB）。同包名小版本升级通常保留数据，但卸装、清存储、换机或误清站点数据会一次性丢失家长最看重的录音资料。目前没有导出/恢复能力，风险随使用时间只增不减。

## 变更内容

- 在日记设置中提供「导出完整备份」：打包全部日记与每日关卡元数据，以及对应录音与配图媒体
- 提供「从备份恢复」：选择备份文件后，经明确确认，**整库覆盖**本机家庭日记数据（含媒体）
- 备份默认**不包含**云 API Key；可选「含密钥」需额外勾选并警示
- 导出/导入过程展示进度；单条媒体缺失时不导致整包失败（该条无声/无图，其余照常）
- **不在本变更范围**：云端自动同步、百度网盘 OAuth、多设备实时合并

## 能力

### 新能力

- `family-diary-backup`: 家庭日记完整备份的导出、分享与覆盖式恢复（含录音与配图）

### 修改的能力

- （无）

## 影响

- `apps/web/src/family/`：新增备份打包/解包逻辑，读写 `store`、`audioDb`、`imageDb`
- `apps/web/src/pages/FamilyStudioSettingsPage.tsx`：导出/恢复入口与进度、确认文案
- 可能新增轻量 zip 依赖（或等价打包方式）及 Capacitor 分享/选文件能力
