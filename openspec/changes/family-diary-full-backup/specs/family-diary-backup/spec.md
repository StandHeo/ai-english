## Purpose

让家长把家庭日记（含每日关卡、语音录音与配图）导出为可带走的完整备份，并在换机或重装后覆盖式恢复到本机。

## ADDED Requirements

### Requirement: 导出完整备份含录音与配图
系统 MUST 允许家长从日记设置导出一份完整备份。备份 MUST 包含全部家庭日记天数元数据（消息、每日迷你关卡与进度等），以及消息关联的语音录音与关卡配图媒体（若本机存在）。导出过程 MUST 向家长展示可感知的进度。默认导出 MUST NOT 包含云 API Key；仅当家长显式勾选「含密钥」时方可写入密钥字段。

#### Scenario: 导出含录音
- **WHEN** 家长已录过多条日记语音并选择导出完整备份（未勾选含密钥）
- **THEN** 系统生成可分享的备份文件，其中包含对应录音媒体，且文件中不含 API Key

#### Scenario: 导出进度可见
- **WHEN** 家长开始导出且媒体数量较多
- **THEN** 界面展示进度或进行中状态，直至完成或失败提示

#### Scenario: 缺某条录音仍完成导出
- **WHEN** 某条消息引用了录音 id，但本机媒体库中已找不到该 Blob
- **THEN** 系统仍完成导出，并在清单中可反映缺失；不因单条缺失而整包失败

### Requirement: 备份可经系统分享带走
导出完成后，系统 MUST 让家长能通过系统分享或保存文件的方式带走备份（例如分享面板、下载到本机文件）。系统 MUST NOT 在本变更中要求将备份上传到自有服务器。

#### Scenario: 导出后可分享
- **WHEN** 完整备份生成成功
- **THEN** 家长可触发系统分享或保存，以便存到微信/文件管理器/网盘 App 等

### Requirement: 从备份覆盖式恢复
系统 MUST 允许家长选择一份有效备份文件并恢复。恢复前 MUST 明确告知将覆盖本机现有家庭日记数据。确认后，系统 MUST 用备份内容替换本机家庭日记存储（元数据与媒体），使恢复后的天数、关卡与可找到的录音/配图可用。恢复过程 MUST 展示进度。无效或无法识别的文件 MUST 拒绝恢复并提示原因。

#### Scenario: 确认后整库覆盖
- **WHEN** 家长选择有效完整备份并确认覆盖
- **THEN** 本机家庭日记被备份内容替换；备份中存在的录音可再次播放

#### Scenario: 取消则不改数据
- **WHEN** 家长在覆盖确认时取消
- **THEN** 本机家庭日记与媒体保持不变

#### Scenario: 无效文件拒绝
- **WHEN** 家长选择非本格式或损坏的文件
- **THEN** 系统不写入本机数据，并提示无法识别或校验失败

#### Scenario: 备份缺媒体时部分恢复
- **WHEN** 备份清单引用某录音但包内无对应媒体文件
- **THEN** 元数据仍恢复成功，该条语音不可播，其余有媒体的条目可播
