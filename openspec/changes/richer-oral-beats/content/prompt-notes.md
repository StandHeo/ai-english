# 更有趣的口语拍说明

## 问题

旧台词几乎全是 `Look!` → `What's this?` → `Say X!`，孩子很快觉得无聊。

## 做法

1. **多样问法**：想要 / 帮忙 / 颜色特征 / 跟读 / 情境（Ready? Say go!）等，同一关两拍不重复机械句式。
2. **`find` 找一找拍**：点对图再继续（苹果、葡萄、野餐、三轮、头盔、铃铛、自行车复习等）。
3. **`success_say`**：成功时说 `Yum!` / `Ding!` / `Zoom!` 等；未配置则播放器轮换短庆祝句。
4. **焦点轻跳**：口语提问时焦点图轻微跳动。

期望词仍保持短词（`apple`、`trike`、`mountain`…），不要求说长句。
