## 背景

见 proposal。瓶颈主要在 App/浏览器直连与 `apps/api` 代理的 Agnes 调用环。

## 目标 / 非目标

**目标：** 滑动窗口限速 + 429 单次退避；文案提示。  
**非目标：** 服务端多实例分布式限流、改免费档配额、砍配图张数。

## 决策

### D1 — 18/60s 滑动窗口

公开 20 RPM；实现用 **18**，避免边界抖动。记录成功发起（或进入飞行）的时间戳队列。

### D2 — chat 与 image 共用一个桶

同一 Agnes Key / 免费档通常共配额；web 模块级单例，api 进程内单例。

### D3 — 等再发，不并行冲

配图本就顺序循环；在每次 Agnes `fetch`/`cloudJson` 前 `await acquire()`。

### D4 — 429 再等约 3–5s 重试一次

与窗口限速叠加。

## 风险

- **[配图总时长变长]** → 文案说明；可接受。  
- **[多标签页各算各的]** → 本机可接受；不追求跨 Tab。
