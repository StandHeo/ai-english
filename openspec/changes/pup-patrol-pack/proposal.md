## 为什么

孩子喜欢汪汪队式的小狗救援故事；现有主题未覆盖这一兴趣。需要新增独立内容包，用短英文词（pup / truck / help 等）继续开口练习。

## 变更内容

- 新增内容包 **`pup-patrol`（小狗救援队）**：约 8 关线性冒险。
- 视觉为**原创**卡通救援小狗与卡车（汪汪队风格），不使用官方角色商标名作为关卡 id 或 expect。
- 首页随 `packs.json` 自动增加入口；进度按 pack 分桶。
- 非目标：官方 IP 授权素材、付费主题。
