## 为什么

华语家庭希望孩子在练口语时看到「自己的生活」而不只是通用插画。仓库已有儿子骑车视频 `tudouqiche.mp4`，适合先落一关家庭骑车场景，验证「看到自己 → 更愿意开口」；同时为日后手动投放家庭素材（卡通贴纸/角色）铺一条可审核的内容路径。

## 变更内容

- 新增 **家庭骑车关**（目标词 `bike`），挂在水果森林线性地图上（梨树园之后、野餐之前）。
- 关卡场景支持 **短视频背景**：进入关卡后短播家庭骑车片，随后定格，避免口语练习时画面持续晃动分心。
- 准备并引用 **卡通化** 自行车道具图与「小骑手」贴纸（手工放入 `content/assets/`，本变更不做 App 内上传）。
- 扩展关卡脚本 schema / 播放器：场景可声明视频资源；静态图关卡行为保持不变。
- 明确非目标：App 内相册上传、自动从视频生成整关、用孩子替换 Bunny 主向导。

## 能力

### 新增能力

- `family-scene-media`：家庭素材（视频场景、卡通贴纸/道具）如何进入已批准关卡；场景视频短播与定格；与静态图场景并存。
- `bike-level-content`：骑车关剧本、目标词、资源约定、地图线性位置，以及通关卡通小骑手贴纸。

### 修改的能力

- （无——主规格尚未归档；本变更以新增能力描述行为，避免与未归档 MVP 变更产生 MODIFIED 冲突。）

## 影响

- `content/levels/pack.json` 与新关 JSON；`content/assets/videos/`、`items/`、贴纸图。
- `apps/web` 关卡页：背景支持 `<video>` 短播后定格；类型与加载器。
- `content/validate.mjs` / schema：校验 `scene.video` 等字段与资源存在性。
- 不影响 ASR/TTS API 契约；不引入家长端上传 UI。
