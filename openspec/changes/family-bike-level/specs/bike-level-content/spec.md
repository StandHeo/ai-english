## Purpose

定义水果森林主题包中的家庭骑车关：目标词、对话拍、资源路径，以及在线性地图上的位置与通关奖励，使孩子在熟悉的骑车情境中练习 bike。

## ADDED Requirements

### Requirement: 交付已批准的骑车关脚本
内容包 MUST 包含一关已批准的骑车关，唯一 id 为 `fruit-09-bike`（或同等约定且写入 pack 的 id），主题可与水果包共存，目标词至少包含 `bike`。

#### Scenario: 按 id 加载骑车关
- **WHEN** 儿童从地图选择骑车关节点
- **THEN** 系统加载该关脚本，并由脚本字段驱动场景视频、对话拍与期望词匹配

### Requirement: 骑车关挂在线性地图梨与野餐之间
`fruit-forest` 内容包的关卡顺序 MUST 在梨树园关之后、野餐关之前插入骑车关，使通关梨树园后解锁骑车关，通关骑车关后解锁野餐关。

#### Scenario: 梨树园通关解锁骑车关
- **WHEN** 儿童完成梨树园关且骑车关原为锁定
- **THEN** 地图上骑车关变为已解锁

#### Scenario: 骑车关通关解锁野餐关
- **WHEN** 儿童完成骑车关且野餐关原为锁定
- **THEN** 地图上野餐关变为已解锁

### Requirement: 骑车关对话拍与口语期望
骑车关 MUST 包含 3 至 6 个对话拍，其中至少两个为提问/回应拍；期望短语 MUST 覆盖 `bike` 与 `a bike` 等合理变体；失败路径 MUST 提供点图兜底。

#### Scenario: 说出 bike 推进
- **WHEN** 儿童在提问拍说出匹配 `bike` 或 `a bike` 的语音（或开发输入等效）
- **THEN** 系统给予成功反馈并进入下一拍

#### Scenario: 口语失败后点图选自行车
- **WHEN** 儿童口语重试达上限
- **THEN** 系统展示含正确自行车图与干扰项的点图选择，选对后仍可推进

### Requirement: 骑车关引用家庭视频与卡通资源
骑车关场景 MUST 引用仓库内家庭骑车视频（如 `assets/videos/tudouqiche.mp4`）；奖励贴纸 MUST 引用卡通小骑手图；焦点/兜底道具 MUST 引用卡通自行车或等效道具图。上述文件 MUST 存在于内容资源目录并由校验脚本检查。

#### Scenario: 校验通过含视频与贴纸资源
- **WHEN** 运行内容校验
- **THEN** 骑车关脚本及其引用的视频、贴纸与道具路径均通过存在性检查
