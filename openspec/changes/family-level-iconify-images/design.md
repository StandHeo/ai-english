## Context

见 `proposal.md`。家庭日记录已有 `images[]`、`applyGeneratedImages`、通义 `generate-images` 与相册选图。配图最终被 `materializeLevelForPlay` 挂到关卡场景/选项。手机 App 需离线可用、控制体积。

## Goals / Non-Goals

**Goals:**

- 端侧本地搜索 Iconify 子集，SVG → data URL → `images[]`
- 日记页「图标配图」入口；可选「生成后自动图标配图」
- 体积可控（数 MB 内），不依赖外网 Iconify API

**Non-Goals:**

- 不打包全量 Iconify / 全量 Font Awesome
- 不替代通义主场景插画质量；首期不追求「公园全景」级场景图
- 不新增服务端搜图路由（除非后续要统一代理）

## Decisions

### 1. 数据来源：裁剪本地 JSON，而非在线 API

- **选择：** 构建时从 `@iconify/json` 导出精简包（首期 `mdi` 为主，可选少量 `twemoji` 若体积允许；若 twemoji 过大则仅 `mdi`）
- **理由：** App 离线、无 Mixed Content、零费用
- **备选：** 运行时调 `api.iconify.design`——需联网且又碰 HTTPS/HTTP，否决为首选

### 2. 搜索策略

- **选择：** 对关卡槽位关键词（英文词 / 选项 id）做规范化后，在图标名与 aliases 上做精确 + 包含匹配；每个槽取最佳一条；无匹配则跳过该槽
- **理由：** 儿童关卡词多为单名词（apple、slide），简单匹配够用
- **备选：** 完整全文引擎 / 中英词典——首期过重

### 3. 渲染

- **选择：** 将 Iconify body 组装为完整 SVG，再 `data:image/svg+xml,...`；正方形画布、浅色背景，便于关卡点选
- **理由：** 与现有 data URL 管线一致，无需解码位图

### 4. UI 与通义关系

- **选择：** 「图标配图」独立按钮；设置增加「生成后自动图标配图」（默认关）。若同时开了通义自动配图，**图标优先于通义**（先图标填空，通义仅在设置单独触发或「重新配图」），避免双倍等待与费用。首期更简单：**自动图标与自动通义互斥提示**，或自动路径只跑图标、通义仍手动「重新配图」。
- **已决：** 自动路径仅支持「自动图标」；通义保持手动 / 其原有自动开关，若两者皆开则**只跑图标**并状态提示「已用图标配图（通义自动已跳过）」——减少意外扣费。

### 5. 主场景槽

- **选择：** 场景槽若无好匹配，用通用 `image`/`landscape`/`forest` 类图标或跳过，不强行用第一个词糊场景
- **理由：** 图标场景弱；留空可由相册/通义补

## Risks / Trade-offs

- [匹配不到冷门词] → 跳过并提示；家长改相册或通义
- [包体积涨] → 只导出常用子集或按名称白名单裁剪；CI/文档写明上限
- [风格与官方 pack 不一致] → 可接受；后续可换 twemoji/自定义
- [许可证] → 选用 Apache/MIT/CC 清晰的集合；文档注明来源

## Migration Plan

1. 增加构建脚本生成 `icon-pack.json`，提交或构建时生成
2. Web 搜索模块 + UI；默认开关关闭
3. 回滚：隐藏按钮 / 去掉 pack 即可，不影响关卡
