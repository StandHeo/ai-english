## Purpose

为家庭日记生成的关卡自动调用通义万相补儿童友好插画，并与相册选图、占位图降级共存，保证关卡仍可当晚开玩。

## ADDED Requirements

### Requirement: 可选自动配图

系统 SHALL 在家长启用自动配图且通义凭证可用时，为当日家庭关卡生成插画资源；未启用或凭证缺失时 MUST 不阻塞关卡生成与游玩。

#### Scenario: 未配置凭证

- **WHEN** 家长生成关卡成功但未配置通义 API Key（客户端与服务端皆无）
- **THEN** 关卡仍保存成功，图片保持占位或已有相册图，并给出可理解的提示（可稍后再配图或去相册选图）

#### Scenario: 已启用且凭证可用

- **WHEN** 家长启用自动配图且存在有效通义凭证，并成功生成关卡脚本
- **THEN** 系统尝试为场景与选项生成插画并写入当日关卡资源

### Requirement: 儿童安全提示词

系统生成通义请求时 MUST 使用儿童友好约束（明亮、卡通/绘本风、无暴力恐怖、适合 4–6 岁），并基于关卡目标词与场景简述构图。

#### Scenario: 按目标词出图

- **WHEN** 关卡含 `target_words` 与 scene.setting
- **THEN** 每张自动图的提示内容 SHALL 反映对应词或场景，且包含儿童安全约束语义

### Requirement: 相册优先于自动图

若家长已为当日关卡挂上相册图片，系统 MUST 在游玩物化时优先使用相册图；自动图仅填充仍为空的槽位或在家长清空相册图后使用。

#### Scenario: 已有相册图

- **WHEN** 当日 `images[]` 非空且家长未请求强制重生成
- **THEN** 游玩使用的主场景图 SHALL 来自相册（或现有 materialize 规则），不以新自动图覆盖已选手动图

### Requirement: 失败可降级

通义调用失败、超时或返回不合规结果时，系统 MUST 保留关卡脚本，图片回退占位或已有资源，并向家长展示简短错误，不得因配图失败回滚整关。

#### Scenario: 通义超时

- **WHEN** 自动配图请求超时或非 2xx
- **THEN** 关卡仍可玩，状态提示配图失败，可重试配图或改用相册

### Requirement: 张数与成本可控

单次自动配图 SHALL 限制生成张数（默认不超过少量场景+选项图，例如合计 ≤ 4），并允许服务端用环境变量设置更严上限。

#### Scenario: 达到上限

- **WHEN** 关卡选项很多需要更多图
- **THEN** 系统只生成上限内的图，其余槽位保持占位，不无限调用

### Requirement: 凭证保管

通义 API Key MUST 仅经服务端使用（环境变量或家长提交后由 API 代理转发，不落日志明文）；浏览器 MUST NOT 直连通义以免暴露密钥与 CORS 问题。

#### Scenario: 客户端请求

- **WHEN** App 或 Web 需要自动配图
- **THEN** 请求 SHALL 打到本项目 `apps/api` 代理，由服务端调用通义
