## Purpose

家长制作台以按日聊天流呈现家庭日记：用气泡发送语音/文字、编辑转写，并在气泡内回放当日口述，供后续拼故事生成关卡。

## ADDED Requirements

### Requirement: 家长门禁后进入聊天式制作台
系统 MUST 仅在通过既有家长门禁后提供家庭日记聊天制作台。儿童游玩路径 MUST NOT 暴露该制作台。

#### Scenario: 门禁后可见聊天制作入口
- **WHEN** 成人通过家长验证并进入家长区
- **THEN** 可找到进入「家庭日记 / 今日聊天制作」的入口

### Requirement: 当日消息以聊天气泡展示
系统 MUST 将选定自然日的家长消息按时间顺序以聊天气泡展示。每条含语音的消息 MUST 提供可触发的回放控件。

#### Scenario: 打开今日台见到已有气泡
- **WHEN** 家长打开制作台且本地已有该日至少一条消息
- **THEN** 系统按顺序展示这些消息气泡

#### Scenario: 语音气泡可回放
- **WHEN** 家长点按一条带录音的消息的回放控件
- **THEN** 系统播放该条消息保存的音频

### Requirement: 支持语音消息与文字消息
系统 MUST 允许家长发送语音消息（录音后转写）与纯文字消息。语音消息 MUST 在消息中同时保留音频与转写文本（转写失败时仍可保留音频并提示重试或手改）。

#### Scenario: 发送文字气泡
- **WHEN** 家长提交一段非空文字
- **THEN** 该日消息列表新增一条文字消息且界面立即显示

#### Scenario: 发送语音气泡
- **WHEN** 家长在可用环境下完成一段录音并确认发送
- **THEN** 该日新增一条含音频的消息，并在转写成功后显示文本（或显示待手改/失败提示）

### Requirement: 可编辑转写文本
系统 MUST 允许家长编辑已有消息的转写/正文文本，且编辑结果 MUST 持久保存到该日消息。

#### Scenario: 修正转写
- **WHEN** 家长修改某条消息文本并确认
- **THEN** 再次打开该日制作台仍看到修正后的文本

### Requirement: DeepSeek Key 不占第一屏
系统 MUST 将 DeepSeek API Key 等生成关卡所需的高级配置放在折叠/次级区域，默认 MUST NOT 抢占聊天主界面第一屏。

#### Scenario: 默认进入聊天主界面
- **WHEN** 家长进入制作台
- **THEN** 首屏以聊天流与发送区为主，API Key 输入默认折叠或隐藏在次级入口后
