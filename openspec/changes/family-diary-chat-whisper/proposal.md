## 为什么

家庭制作台目前更像「拼草稿再生成关卡」：语音转写依赖浏览器 SpeechRecognition / 云端 Whisper，故事不以聊天气泡呈现，也难以按日回听家长口述。家长更需要**聊天式日记台**：按自然日留下可回放的语音气泡，并在手机上用**免费端侧 Whisper**转写；关卡口语继续走（或预留）Vosk，两者互不抢引擎。

## 变更内容

- 将家庭制作台升级为**按日聊天流**：每条家长消息可含录音（可回放）+ 转写文本；按日历日期存取与回看。
- 引入 **Capacitor 端侧 Whisper**（优先 tiny / int8 等可离线包）专用于家庭日记转写；**不**把云端 OpenAI Whisper 作为日记主路径。
- DeepSeek API Key 等高级配置**收纳折叠**，默认不抢第一屏；生成关卡流程仍可用，但不改关卡拍引擎。
- **明确隔离**：日记 ASR = Whisper；关卡口语 = Vosk（本机已有或后续接入）。本变更不改写关卡 Vosk / 拍练习逻辑。
- **非目标**：浏览器内跑完整 Whisper WASM 作为正式主路径、云端付费 ASR 主路径、儿童自由聊天、多设备云同步、替换官方 pack。

## 能力

### 新增能力

- `family-diary-chat`：家长制作台以聊天气泡呈现当日消息；支持录音发送、文本编辑、按日回看与气泡内回放。
- `on-device-whisper-diary`：在 Capacitor 原生环境用端侧 Whisper 将日记录音转写为文本；无原生能力时给出明确降级提示（不默认走云端 OpenAI）。
- `family-diary-audio-store`：按自然日持久化消息列表（含音频引用与转写），供聊天台与日历侧回听。

### 修改的能力

- （无——主规格目录尚未归档 `family-story-intake` 等；本变更以新增能力描述行为。实现上会替换/增强既有制作台 UI 与存储字段，但不单独开 delta 改未归档主规格。）

## 影响

- `apps/web`：`FamilyStudioPage` 聊天 UI；`family/store` 消息与音频字段；家长设置里 DeepSeek Key 折叠；可选日历页展示「有语音」标记。
- Capacitor / Android：端侧 Whisper 插件或原生模块、模型资源打包与首次加载；真机/APK 才能验证完整转写。
- `apps/api`：日记主路径**不再依赖**云端 Whisper；现有 `/api/asr` 可保留给其他用途，但不作为日记默认。
- 关卡口语 / Vosk：本变更范围外，保持可并存。
- 文档：端侧模型体积、首次下载/内置说明、浏览器预览限制。
