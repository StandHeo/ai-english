## 为什么

官方主题包与孩子「今天真实经历」脱节；家长每晚想把亲子复盘变成可开口的英语小关卡，又必须和现有手写 pack 分开。需要一套**手机上当晚就能玩**的家庭日记关卡工作室：语音/文字收集今日故事 → DeepSeek 生成结构化关卡 → 相册选图（求快）→ 按日历攒下来。

## 变更内容

- 新增与官方 pack **独立**的家庭日历关卡体系（按日期存储与游玩，旧关可回看）。
- 家长门禁后的**制作台（手机优先）**：多段语音或文字拼「今日故事」；可配置 DeepSeek API Key。
- 调用 DeepSeek 将中文故事转为**符合现有 LevelScript 约束**的一关（短词、可当晚玩）；生成后尽快可玩，质量以「能开口」优先于手写包精美度。
- 配图求快：LLM 给出相册搜索提示词；家长用系统相册/文件选择器选图；未选则占位图，不阻塞开玩。
- **非目标**：App 自动全文检索整机相册、Cursor API Key 复用、云同步多设备账号、文生图付费管线、儿童端自由聊天、改写官方水果/机器人等 pack。

## 能力

### 新增能力

- `family-story-intake`：家长在手机上用语音/文字采集并编辑「今日故事」草稿。
- `deepseek-level-generate`：使用可配置的 DeepSeek API Key，将故事生成并通过校验的关卡脚本（及配图提示）。
- `family-calendar-play`：按日期囤关与游玩的独立入口/进度，与官方主题包隔离。
- `album-image-attach`：根据提示从手机相册/文件选择器选图挂到当日关卡，支持占位兜底。

### 修改的能力

- （无——主规格目录若尚未归档完整 MVP，本变更以新增能力描述行为。）

## 影响

- `apps/web`：家长制作台、设置（API Key）、家庭日历儿童入口与路由；本地/IndexedDB 等存储当日关与图。
- `apps/api`：DeepSeek 代理（避免浏览器 CORS、保管请求形态）；可选扩展 ASR 仅服务故事采集。
- 存储：按日关卡与资源，不写入官方 `content/levels/packs/*` 发布包（或仅文档约定运行时用户内容目录）。
- 文档：手机 HTTPS/麦克风、DeepSeek Key 配置说明。
