## 背景

参见 `proposal.md` 动机。当前关卡由 `LevelPage` 解释线性 `beats[]`（introduce / ask / find），口语用 `expect` + `matchExpect`，TTS 走 Piper/系统，贴纸在关卡成功结算时发放。已有「儿童无自由聊天」产品边界；家长侧 DeepSeek 只用于生成关卡脚本。

## 目标 / 非目标

**目标：**

- 用可选 `beep_talk` 对话图扩展关卡数据，不破坏无该字段的旧关。
- 在播放器内衔接「末拍成功 → Beep 节点循环 → 庆祝+贴纸」。
- 匹配与兜底复用现有口语哲学；Beep 用独立形象与固定 TTS 路由（可调 pitch）。
- 先落地 1～2 关样板验证，再铺内容。

**非目标：**

- 儿童路径 LLM / 云端回合对话 API。
- 首页独立「和机器人聊天」模式。
- 一次为全库每关写满 `beep_talk`。
- 替换 Bunny 主线向导；新 ASR 引擎。
- 可跳过整段 Beep（首版）。

## 决策

### D1 — 数据：关卡内嵌可选 `beep_talk`，而非独立 talk 包

- **选择：** `LevelScript.beep_talk?: { start: string, nodes: Record<string, TalkNode> }`（字段名可微调，语义不变）。
- **原因：** 对话贴合该关词表，跟关卡同文件审核；无字段则零行为变化。
- **备选：** 全局 dialogues 目录按 levelId 引用（多一层间接，首版不必要）。

### D2 — 播放：LevelPage 增 phase，不新开路由

- **选择：** 在现有 `/level/:levelId` 增加 phase（如 `beepTalk`），末拍成功切入；结束 phase 再走现有 celebrate / 进度写入。
- **原因：** 进度、返回、家长时长限制已挂在关卡页；少一条路由。
- **备选：** `/level/:id/beep` 独立页（边界清晰，但状态传递与「未完成返回」更碎）。

### D3 — 节点推进：显式 next / on_fail_next

- **选择：** 成功走 `next`；兜底成功走 `on_fail_next`（可等于 `next`）；结束用 `next: null` 或 `end: true`。
- **原因：** 小图可控，避免隐式线性假设。
- **备选：** 纯数组顺序（写起来快，难表达「失败也前进但说不同句」）。

### D4 — 匹配：复用 `matchExpect`，节点级同义写在 expect[]

- **选择：** 不引入 LLM；同义全部写进该节点 `expect`。
- **原因：** 与 MVP D4 一致，童声 ASR 下可预期。
- **备选：** 全局同义词典（可后加）。

### D5 — 贴纸时机

- **选择：** 有 `beep_talk` 时，**推迟** `completeLevel` / 发贴纸到对话结束；中途返回地图视为未通关（不写 completed）。
- **原因：** 避免「贴纸已到手、对话可弃」。
- **备选：** 末拍先发贴纸再对话（削弱尾声动机）。

### D6 — 拾音

- **选择：** 复用 `usePressToTalk`；Beep 轮可将自动停录略延长（如 ~5s），仍手动按键。
- **原因：** 4–6 岁需要明确「我在说」；对话句可能稍长于单目标词。
- **备选：** 全程 VAD（首版不做）。

### D7 — 样板范围

- **选择：** 优先在 `robot-lab` 选 1～2 关写贴合词的 Beep 尾声（人设一致）；若资源不足可改水果包一关。
- **原因：** Beep 与机器人主题最贴；验证闭环足够。

## 风险 / 权衡

- **[风险] 每关内容成本** → 缓解：字段可选；首版仅样板关；后续可批量补。
- **[风险] 童声 ASR 在短对话句上更差** → 缓解：短 expect、同义、强 hint、点图兜底、不可跳过但必能走完。
- **[风险] 关卡变长导致注意力下降** → 缓解：强制 3～5 节点；单节点一句。
- **[权衡] 不可跳过** → 体验更完整，但失败路径必须极顺；若真机反馈挫败再考虑「跳过不发贴纸」。
- **[权衡] 嵌在 LevelPage** → 实现快，组件会再胖一层；必要时再抽 `BeepTalkPanel`。

## 待决问题

- 样板最终落在 robot-lab 哪 1～2 个 `levelId`（实现前选定即可）。
- Beep 立绘：新资产 vs 临时用现有 robot 图 + 文案区分（可先临时图）。
- 家庭自制关（DeepSeek）是否生成 `beep_talk`：首版 **不生成**，保持可选空。
