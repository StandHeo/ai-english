## 为什么

现有关卡以线性口语拍为主，孩子练的是「听一句、说目标词」，缺少一段像在和角色交流的短对话。在不引入儿童自由聊天 / LLM 的前提下，用**约束对话图**作为每关尾声，既能增加「和机器人说英语」的乐趣，又保持可预期匹配与永不卡死。

## 变更内容

- 关卡脚本新增可选 **`beep_talk`（约束对话图）**：3～5 个节点，含机器人台词、expect/同义、提示与点图兜底、成功/失败后的下一节点。
- 播放器：当本关含 `beep_talk` 时，**最后一拍成功后**进入独立机器人 **Beep** 的短对话；对话走完后再庆祝并发贴纸。
- 无 `beep_talk` 的关卡行为不变（拍完即庆祝/发贴纸）。
- 首版内容：至少为 **1 个主题包内 1～2 关** 编写贴合该关目标词的 Beep 尾声对话（样板）；不要求一次铺满全库。
- 儿童路径 **不** 提供开放式自由聊天，**不** 在儿童回合调用 LLM。
- 首版对话 **不可跳过**（靠强兜底保证一定能走完）。

## 能力

### 新增能力

- `beep-tail-talk`：关卡尾声 Beep 约束对话（内容 schema、播放衔接、匹配与兜底、贴纸发放时机、样板关）

### 修改的能力

- （无——主规格目录尚无已同步条目；以新增能力描述行为）

## 影响

- 内容：`content/levels/schema.json`、部分关卡 JSON、可选 Beep 立绘资源
- 客户端：`apps/web/src/types.ts`、`LevelPage`（或尾声子流程）、匹配/TTS 复用、进度发贴纸时机
- 语音：复用现有按键说话 + Piper/系统 TTS；可选略延长拾音窗口；不新增云端对话 API
- 产品边界：明确「约束对话 ≠ 自由聊天」，与既有「儿童无自由聊天」决策一致
