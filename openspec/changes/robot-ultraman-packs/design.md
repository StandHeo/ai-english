## 背景

动机见 `proposal.md`。应用已支持多 pack 首页与按 pack 分桶进度。本变更在不改 ASR/关卡引擎的前提下，新增两个兴趣主题内容包。

## 目标 / 非目标

**目标：**

- 落地 `robot-lab` 与 `hero-world` 各约八关已批准脚本 + 卡通资产。
- 首页自动出现四个主题大图入口；进度互不串包。
- 英雄包使用原创「光之英雄」形象，口语词为通用英文（hero / light / kick…），避免官方商标字符串作为关卡 id 或 expect。

**非目标：**

- 官方奥特曼 IP 授权、真实角色名（Tiga 等）。
- 新对话拍类型、云同步、主题商店。
- 家庭视频（本季不接）。

## 决策

### D1 — Pack 标识与展示名

| packId | 英文 title | 家长页中文 |
|--------|------------|------------|
| `robot-lab` | Robot Lab | 机器人实验室 |
| `hero-world` | Hero World | 英雄世界 |

- **原因：** id 清晰；儿童端少文字靠大图识别；家长页用中文方便。
- **备选：** packId 用 `ultraman-*`（商标风险更高，否决）。

### D2 — 机器人第一季关卡表

| 顺序 | id | 主词 | 场景要点 |
|------|-----|------|----------|
| 1 | `robot-01-robot` | robot | 实验室见面 |
| 2 | `robot-02-arm` | arm | 机械臂台 |
| 3 | `robot-03-wheel` | wheel | 轮子车库 |
| 4 | `robot-04-button` | button | 按钮面板 |
| 5 | `robot-05-beep` | beep | 蜂鸣大厅 |
| 6 | `robot-06-gear` | gear | 齿轮工坊 |
| 7 | `robot-07-friend` | friend | 机器人朋友 |
| 8 | `robot-08-review` | 复习 robot, arm, beep | 实验室派对 |

### D3 — 英雄第一季关卡表

| 顺序 | id | 主词 | 场景要点 |
|------|-----|------|----------|
| 1 | `hero-01-hero` | hero | 英雄城市 |
| 2 | `hero-02-monster` | monster | 友善小怪兽洞（非恐怖） |
| 3 | `hero-03-light` | light | 光之天空 |
| 4 | `hero-04-fly` | fly | 云上飞行 |
| 5 | `hero-05-kick` | kick | 训练场踢腿 |
| 6 | `hero-06-shield` | shield | 护盾堡垒 |
| 7 | `hero-07-go` | go | 出发救援 |
| 8 | `hero-08-review` | 复习 hero, light, kick | 英雄庆祝 |

- **原因：** 词短、4–6 岁可开口；怪兽保持友好卡通。
- **备选：** 用 beam/ultraman 等词（过难或商标，否决）。

### D4 — 资产风格

- **选择：** 与现有水果/自行车一致的儿童卡通 sticker / 场景插画；英雄为银红配色原创光之战士，**非**官方奥特曼拷贝。
- **原因：** 视觉连贯 + 合规。

### D5 — 进度默认桶

- **选择：** `defaultState` 增加两 pack 空桶（首关 `robot-01-robot` / `hero-01-hero`）；`getPackProgress` 按 packId 推断首关，避免硬编码仅水果/自行车。
- **原因：** 新用户四包均可开玩；旧 localStorage 合并时缺桶则回退空桶。

### D6 — 首页布局

- **选择：** 保持数据驱动 `theme-grid`；样式改为可滚动的双列或更紧凑卡片，避免四张竖排过高。
- **原因：** 手机首屏能看到至少两个主题。

## 风险 / 权衡

- **商标观感：** 家长可能期待「真奥特曼」——文档与家长文案写明「原创英雄、奥特曼风格」。
- **首页拥挤：** 四入口需紧凑布局与滚动。
- **资产量：** 约 30 张图，实现时批量生成并校验路径存在。
