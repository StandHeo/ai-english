# 英雄世界 · 第一季剧情纲要

向导：Bunny。场景：明亮的英雄城市与训练场。  
视觉为**原创**卡通光之英雄（银红配色、奥特曼风格），不使用官方商标角色名。

1. **Hero** — 认识光之英雄  
2. **Monster** — 友好的小怪兽（不吓人）  
3. **Light** — 英雄的光  
4. **Fly** — 飞上天空  
5. **Kick** — 训练场踢腿  
6. **Shield** — 闪亮护盾  
7. **Go** — 出发帮忙  
8. **Review** — 英雄庆祝，复习 hero / light / kick  

口语目标词均为通用英文短词，适合 4–6 岁开口。
