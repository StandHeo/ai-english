## Purpose

家庭日记关卡配图改为仅使用云端文生图（及家长相册），不再提供本地 Iconify 图标配图入口与自动路径。

## ADDED Requirements

### Requirement: 无本地图标配图
系统 MUST NOT 在家庭日记设置或日记页提供「图标配图 / 自动图标配图」。生成关卡后的自动配图 MUST 仅在开启「自动云端配图」时调用当前云端提供方。

#### Scenario: 设置里只有云端自动配图
- **WHEN** 家长打开日记设置的配图区域
- **THEN** 可见自动云端配图开关与通义/Agnes 选择，MUST NOT 出现自动图标配图勾选

#### Scenario: 日记页无图标按钮
- **WHEN** 家长查看已生成关卡的配图操作
- **THEN** 可使用相册与云端配图，MUST NOT 出现「图标配图」按钮

### Requirement: 自动云端仍可选
「生成关卡后自动云端配图」MAY 默认关闭。关闭时生成关卡成功 MUST NOT 自动调云；家长可手动点云端配图。开启且具备对应 Key 时 MUST 按槽位自动云端配图（含场景背景槽与道具槽）。

#### Scenario: 关闭自动时不调云
- **WHEN** 自动云端配图关闭且家长生成关卡成功
- **THEN** 不发起云端配图请求，可提示手动配图
