## 为什么

官方主题包（如水果）是「多关 × 每关一词 + 专属背景」；当前家庭每日关是「一天一关塞很多词 + 一张背景」，孩子体验和家长心理模型都对不齐。需要让「生成今日关卡」产出**一天一个迷你 pack**，结构对齐官方。

> 取代未实施的 `family-scene-style-editable-slots`（单关改 prompt / 可编辑槽位）；可编辑配图词并入本变更。

## 变更内容

- **BREAKING（新生成路径）**：日记生成结果从单个 `level` 改为当日迷你 `pack`（多关列表）；默认 **3–5 关**（与设置里关键词上限对齐并夹紧到 3–5）。
- 每关约 **1 个主词**、短地点 `scene.setting`、**专属背景图**（+ 必要道具/干扰项图），玩法 beats 贴近官方单关。
- 日历点当天 → **关卡列表/迷你地图** → 再进单关游玩；通关进度按关记录，当日全部通关才算「今天完成」。
- **兼容**：已有「一天一关」旧数据仍可直接玩，不强制迁移。
- 家长可在日记页按关编辑场景/配图主题（中英文），再触发该关或整包云端配图。
- 收紧 LLM / 文生图 prompt，使每关观感接近官方「一词一景」。
