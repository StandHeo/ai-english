## Purpose

为家庭日记迷你关云端配图提供默认可玩、更生动的儿童绘本风格提示词，替代「单词闪卡」式死板构图，同时保持无文字、无暴力等安全约束。

## ADDED Requirements

### Requirement: 默认道具图非闪卡构图
系统内置的道具与干扰图提示词模板 MUST NOT 要求「单词闪卡」、主体固定占画面约七成、或强制干净浅色纯色背景且禁止任何场景元素。模板 MUST 引导模型绘制单一清晰主体、柔和儿童绘本气质、可带极简环境点缀，且主体仍易于辨认。场景背景模板 MUST 按方形出图友好撰写，MUST NOT 强制竖版远景手机封面构图。

#### Scenario: 内置道具模板不含闪卡用语
- **WHEN** 读取 web 与 api 同步的内置默认 `itemTemplate` / `distractorTemplate`
- **THEN** 文案不含「单词闪卡」，也不含「占画面约七成」与「干净的浅色柔和纯色背景」这类强制贴纸构图措辞

#### Scenario: 场景模板按方图友好
- **WHEN** 读取内置默认 `sceneTemplate`
- **THEN** 文案不要求「竖版竖构图」作为硬性构图，并仍描述开阔、适合游戏背景的环境主题

### Requirement: 安全与负向约束保留
系统 MUST 继续禁止画面中出现文字、字母、数字、招牌标志与暴力恐怖血腥内容。负向提示 MUST 保留对文字/水印/暴力等约束；MAY 放宽对「写实照片」的一刀切禁用，以便允许柔和体积感，但仍 MUST NOT 鼓励成人向写实或低龄不宜内容。

#### Scenario: 安全前缀仍禁文字与暴力
- **WHEN** 使用内置默认 `safetyPrefix` 渲染任一槽位提示词
- **THEN** 合成提示词包含禁止文字/字母/数字/招牌与无暴力恐怖血腥的约束

### Requirement: 运营自定义配置不被静默覆盖
若服务端已持久化运营自定义的 `image_prompt_config`，部署本变更更新内置默认后，系统 MUST NOT 在普通启动时静默用新默认覆盖该自定义配置。新装或显式「恢复默认」时 MUST 采用新的内置默认。

#### Scenario: 已有自定义配置保持
- **WHEN** 数据库中已有非默认的 `image_prompt_config` 且未请求恢复默认
- **THEN** `GET /api/family/image-prompt-config` 仍返回该自定义内容，不被新 baked 默认静默替换
